## 核心发现

### 题型格局
- **国考**：5题，概括(10-15)+分析(10-15)+应用文(20)+对策(20)+大作文(35)
- **江苏**：4题，概括(20)+分析(15-20)+应用文(20-25)+大作文(40)
- 国考更重深度分析，江苏更重实务应用

### 采分点规律
- 概括题：60-70%直接提取原文
- 对策题：30-40%需引申推断
- 大作文：50-60%需引申推断
- 识别"真采分点"的方法：80%以上机构共识的才是钢性采分点

### 两考差异关键
- 国考区分度在综合分析题，江苏区分度在大作文
- 江苏采分点更"浅"（更多原文提取），国考更"深"（更多概括提炼）
- 两考大作文分值不同（35 vs 40），评分标准需分别建立
