# 申论评分标准细则 v1.0

> 基于2014-2025国考（28份）+ 2019-2025江苏（42份）真题与多机构答案的系统分析
> 编制：评分架构师

---

## 使用说明

本细则按"题型—评分模式—具体标准"三层结构编排。使用时：
1. 先判断题目属于哪种评分模式（按点给分/按档给分/混合型）
2. 再按对应模式的标准进行评分
3. 评分时应遵循"先定档/定区间，再微调"的原则

---

## 第一部分：按点给分题评分细则

### 适用范围

- 概括归纳题（所有类型）
- 问题梳理题
- 要素分析题（原因/影响/表现等）

### 评分流程

```
步骤1：通读答案，标记采分点
步骤2：对照标准答案核对每个采分点的匹配度
步骤3：根据匹配度给每个采分点打分
步骤4：检查条理性（分类归纳）加分/扣分
步骤5：检查字数、卷面，做最终调整
```

### 采分点匹配规则

| 匹配程度 | 说明 | 赋分比例 |
|---------|------|---------|
| 完全匹配 | 关键词与标准答案一致或语义等价 | 100% |
| 部分匹配 | 关键词核心意思正确但表述不够精准 | 50-70% |
| 不匹配 | 关键词错误或缺失 | 0% |

### 国考概括题评分标准模板（10-15分）

**示例：2025副省第1题（15分）**

| 采分点 | 分值 | 标准表述 | 等价表述示例 |
|--------|------|---------|------------|
| 原型黄河 | 2分 | 实体的原型黄河/自然黄河 | 物理黄河/实体黄河 |
| 数字孪生黄河 | 2分 | 把原型黄河"装进"计算机 | 数字黄河/虚拟黄河/信息化黄河 |
| 模型黄河 | 2分 | 把黄河"放进"实验室 | 模拟黄河/物理模型黄河 |
| 原型为基础提供数据 | 2分 | 构建监测感知网络获取动态数据 | 原型黄河提供基础数据支撑 |
| 数字孪生具有"四预"功能 | 2分 | 预报、预警、预演、预案 | "四预"模拟推演 |
| 模型黄河提供物理参数 | 2分 | 为治理提供物理参数和支撑引领 | 提供技术支撑和理论依据 |
| 三者协同关系 | 1分 | 科技让三条黄河协同关联 | 系统性、整体性、协同性 |
| 条理性 | 2分 | 分类清晰，层次分明 | — |

### 江苏概括题评分标准模板（20分）

**示例：2025A第1题（20分）**

| 采分点 | 分值 | 说明 |
|--------|------|------|
| 每个成效案例 | 3-4分 | 共5个案例（南京/西安/山西/自贡/苏州），每个覆盖2-3个采分点 |
| 概括完整性 | 3分 | 是否全覆盖5个成效 |
| 一段话表述 | 2分 | 是否按要求用一段话（非分条）表达 |

### 对策题评分标准模板（20-25分）

**问题部分（约占40%）**：
- 每条问题1-2分
- 需准确概括材料中提到的困境
- 分类清晰（如内部问题/外部问题，或人才/技术/市场等维度）

**对策部分（约占60%）**：
- 每条对策2-3分
- 针对性：是否针对上述问题提出（占1分）
- 可行性：是否具体可操作（占1分）
- 层次性：是否有逻辑顺序（占1分）

## 第二部分：按档给分题评分细则

### 大作文评分操作流程

```
步骤1（快速定档）：
  - 看标题和开头 → 判断是否扣题、有无观点
  - 看每段首句 → 判断分论点是否清晰
  - 看结尾 → 判断是否有升华

步骤2（精细调整）：
  - 看论据使用是否充实（材料内+材料外）
  - 看语言表达是否有文采
  - 看结构是否严谨（总-分-总、递进/并列）

步骤3（扣分项检查）：
  - 是否偏离主题
  - 是否有抄袭材料嫌疑
  - 字数是否达标
  - 卷面是否整洁
```

### 大作文35分制评分细则（国考）

| 档次 | 分数区间 | 中心论点 | 结构逻辑 | 内容论证 | 语言表达 |
|------|---------|---------|---------|---------|---------|
| 一类上 | 33-35 | 深刻、新颖、准确 | 严谨周密，有递进 | 论据充实，内外结合 | 文采斐然，表达精准 |
| 一类下 | 28-32 | 鲜明、准确 | 完整有序，层次分明 | 论据较充实，材料运用好 | 流畅生动，用词得当 |
| 二类上 | 24-27 | 明确 | 完整，基本有序 | 论据较充分，有材料案例 | 通顺，偶有亮点 |
| 二类下 | 20-23 | 基本明确 | 基本完整 | 论据单薄 | 基本通顺 |
| 三类上 | 15-19 | 不够明确/有偏差 | 不够完整 | 内容空洞，抄材料 | 语病较多 |
| 三类下 | 11-14 | 偏离题意 | 结构混乱 | 大量抄袭材料 | 语言不通顺 |
| 四类 | 0-10 | 完全跑题 | 无结构 | 抄袭或空白 | 极差 |

### 大作文40分制评分细则（江苏）

| 档次 | 分数区间 | 核心特征 |
|------|---------|---------|
| 一类上 | 37-40 | 观点深刻、立意高远、结构严谨、语言出彩 |
| 一类下 | 32-36 | 观点明确、结构完整、论据充实、语言流畅 |
| 二类上 | 28-31 | 观点较明确、结构较完整、论据较充分、语言通顺 |
| 二类下 | 24-27 | 观点基本明确、结构基本完整、论据不足、语言基本通顺 |
| 三类上 | 18-23 | 观点模糊或略有偏差、结构松散、内容空洞 |
| 三类下 | 10-17 | 偏离题意、结构混乱、抄袭材料 |
| 四类 | 0-9 | 完全跑题、字数严重不足 |

### 扣分细则

| 扣分项 | 扣分幅度 |
|--------|---------|
| 标题缺失 | -2分 |
| 字数不足（每少50字） | -1分 |
| 字数少于600字 | 直接进入三/四类 |
| 卷面涂改严重 | -1至-3分 |
| 错别字（每3个） | -1分 |
| 明显抄袭给定材料 | 降一档处理 |

## 第三部分：混合型题评分细则

### 应用文评分标准模板（20分制）

**评分维度权重**：

| 维度 | 权重 | 具体标准 |
|------|------|---------|
| 内容要点 | 12分（60%） | 材料关键信息是否全面覆盖（缺一个要点扣2-3分） |
| 格式规范 | 2分（10%） | 文体格式是否正确（标题/称谓/落款/日期等） |
| 逻辑结构 | 3分（15%） | 层次是否清晰、过渡是否自然 |
| 语言表达 | 3分（15%） | 是否符合文体要求、是否生动/精准 |

**常见文体格式要点**：

| 文体 | 格式要求 | 语言风格 |
|------|---------|---------|
| 展板文稿 | 有标题，分段落，无固定称谓 | 生动形象，有感染力 |
| 简报/简讯 | 标题+导语+正文，含时间地点事件要素 | 简洁明了，要素齐全 |
| 调研报告提纲 | 题目+背景+问题+建议的结构 | 客观严谨 |
| 宣传稿 | 标题+正文+号召结尾 | 有感染力，有动员性 |
| 发言稿 | 称谓+开场白+正文+结束语 | 口语化但正式 |

### 综合分析题评分标准模板（10-15分制）

**以2025副省第2题（10分）为例**：

| 评分维度 | 分值 | 一类（8-10分） | 二类（5-7分） | 三类（2-4分） |
|---------|------|---------------|--------------|--------------|
| 观点准确 | 3分 | 准确理解"不是产业竟是产业"的深层含义 | 理解基本正确 | 理解偏差 |
| 分析透彻 | 4分 | 结合材料分析：网红经济的教训+"竟是山"理念+徐庄实践 | 有分析但较浅 | 分析浮于表面或空谈 |
| 逻辑清晰 | 2分 | 表态→解释→分析→总结，层次分明 | 基本有逻辑 | 逻辑混乱 |
| 语言精炼 | 1分 | 表达精准简洁 | 基本通顺 | 语病较多 |

**综合分析题的标准结构**：

```
第一层（表态+解释）：这句话的意思是……（2-3句话点明核心）
第二层（分析）：具体来说……（结合材料分析原因/表现/影响，4-6句）
第三层（总结）：因此/对此，……（2-3句话总结或延伸）
```

## 第四部分：特殊评分规则

### 字数违规处理

| 题型 | 超出幅度 | 扣分标准 |
|------|---------|---------|
| 概括类 | 超出规定字数的10%以内 | 不扣分 |
| 概括类 | 超出10%-20% | -1分 |
| 概括类 | 超出20%以上 | -2分 |
| 应用文 | 超出或不足15%以内 | 不扣分 |
| 应用文 | 超出或不足15%-30% | -1至-2分 |
| 大作文 | 不足规定字数90% | 每少50字-1分 |
| 大作文 | 不足规定字数60% | 三档以下处理 |

### 卷面与书写

- 明显涂改影响阅读：-1至-2分
- 字迹难以辨认：酌情扣分
- 使用非黑色签字笔：不扣分（但建议统一要求）

### 雷同卷处理

- 两份或多份答案大面积雷同（超过60%）：重新评分并标注异常

## 第五部分：题型特定评分要点备忘

### 国考特有题型

**语句理解题**（10-15分）：
- 不能只做字面解释，必须结合材料上下文
- 需要有"为什么"的分析层次
- 结尾可以适度引申但不能过度发挥

**"启示类"综合分析**（15分）：
- 需要从案例中提炼出可推广的经验
- 启示不能太具体（否则失去普适性）
- 也不能太抽象（否则失去操作性）

### 江苏特有题型

**评析题**（15分）：
- 必须明确表态（肯定/否定/辩证看待）
- 既要分析合理性也要指出局限性
- 最后要有正确导向的总结

**简讯写作**（20分）：
- 必须包含5W要素（时间、地点、人物、事件、意义）
- 语言简洁，突出亮点
- 字数控制严格，超出扣分明显

## 第六部分：评分一致性保障

### 双评规则（建议）

- 大作文（35-40分）和综合分析题（10-15分）：每份试卷由2位评卷员独立评分
- 评分差超过该题总分20%时（如大作文差7分以上）：交由组长评定
- 其他题型：可由1位评卷员评分，但需每日抽查5%进行一致性检验

### 评分员训练要点

1. **校准训练**：每位评分员先独立评30份预试卷，与标准答案比对，确保对采分点理解一致
2. **边评边校准**：每评50份做一次一致性检验
3. **标杆卷**：每档保留3-5份标杆卷，供评分员参考

### 异常答案处理

| 异常类型 | 处理方式 |
|---------|---------|
| 观点明显偏离主流价值观 | 标记、上报、按零分处理 |
| 大作文全文抄袭材料 | 进入三类以下 |
| 空白卷或完全答非所问 | 零分 |
| 字迹完全无法辨认 | 尝试辨认后仍无法确认的，按保守估分 |
