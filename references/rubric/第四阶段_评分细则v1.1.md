# 申论评分标准细则 v1.1（校准版）

> 基于2014-2025国考（28份）+ 2019-2025江苏（42份）真题与多机构答案的系统分析
> 校准依据：阅卷顾问真实阅卷经验（2023-2024年真题阅卷反馈）
> 编制：评分架构师 | 版本：v1.1（校准版）

---

## 使用说明

本细则按"题型—评分模式—具体标准"三层结构编排。使用时：
1. 先判断题目属于哪种评分模式（按点给分/按档给分/混合型）
2. 再按对应模式的标准进行评分
3. 评分时应遵循"先定档/定区间，再微调"的原则
4. **重要**：每大题须先判断是否适用"行政执法"的特殊标准

## 第一部分：按点给分题评分细则

### 适用范围
- 概括归纳题（所有类型）
- 问题梳理题
- 要素分析题（原因/影响/表现等）

### ⚠️ 核心原则（阅卷顾问校准）

> **评分必须用"原文关键词"，不能用"概括词"** 
> 
> 真实阅卷只认原文中出现的关键词/短语。考生写"概括提炼后的上位词"不给分。
> 
> ✅ 给分："提篮拱桥""边建边拆""废料再利用"
> ❌ 不给分："设计精妙""生态友好""技术先进"

#### 具体执行规则

| 答案类型 | 示例 | 是否给分 |
|---------|------|---------|
| 原文关键词直接使用 | 数字孪生黄河、原型黄河 | ✅ 满分 |
| 原文关键词近义替换 | 实体黄河（代替原型黄河） | ✅ 给分 |
| 概括提炼上位词 | 智能化治理（代替具体技术细节） | ❌ 不给分 |
| 过度发挥/拔高 | 习近平生态文明思想（概括题中出现） | ❌ 不给分，甚至扣分 |

### 评分流程
```
步骤1：通读答案，标记"原文关键词"（不是概括词！）
步骤2：对照标准答案核对每个关键词的匹配度
步骤3：根据匹配度给每个采分点打分
步骤4：检查条理性（分类归纳）加分/扣分
步骤5：检查字数、卷面，做最终调整
```

### 采分点匹配规则

| 匹配程度 | 说明 | 赋分比例 |
|---------|------|---------|
| 完全匹配 | 原文关键词或语义等价的近义词 | 100% |
| 部分匹配 | 关键词核心意思正确但表述不够精准 | 50-70% |
| 概括词替代 | 使用上位概括词而非原文关键词 | 0%（阅卷不给分） |
| 缺失/错误 | 采分点内容完全缺失或错误 | 0% |

### 国考概括题评分标准模板（10-15分）

**示例：2025副省第1题（15分）——校准要点**

| 采分点 | 分值 | 标准表述（原文关键词） | 等价表述（可给分） |
|--------|------|---------|------------|
| 原型黄河 | 2分 | 实体的原型黄河/物理上的黄河 | 实体黄河/自然黄河 |
| 数字孪生黄河 | 2分 | 把原型黄河"装进"计算机 | 数字黄河/虚拟黄河（但**不是**"智慧黄河"） |
| 模型黄河 | 2分 | 把黄河"放进"实验室 | 模拟黄河/物理模型 |
| 原型为基础提供数据 | 2分 | 构建监测感知网络获取动态数据 | 原型黄河提供基础数据 |
| 数字孪生具有"四预" | 2分 | 预报、预警、预演、预案 | 四预功能/四预模拟推演 |
| 模型提供物理参数 | 2分 | 提供物理参数和支撑引领 | 提供技术支撑和理论依据 |
| 三者协同关系 | 1分 | 科技让三条黄河协同关联 | 系统性/整体性/协同性 |
| 条理性分 | 2分 | 分类清晰（不可与要点重复给分） | — |

**注意**：阅卷顾问反馈，这条注释需加在每条标准后面。

### 江苏概括题评分标准模板（20分）

**示例：2025A第1题（20分）——校准要点**

| 评分维度 | 分值 | 校准说明 |
|---------|------|---------|
| 每个成效案例 | 3-4分 | 要求写出**具体案例名称**（如"南京《大梦红楼》""山西跟着悟空游山西"），只写"文旅融合成效显著"不给分 |
| 概括完整性 | 3分 | 5个案例需全覆盖，缺1个扣对应分数 |
| 一段话表述 | 2分 | 是否按要求用一段话表达，分条列项会扣分 |
| **原文关键词密度** | 隐性扣分 | 全文如果都是概括性语言无具体案例/数据，扣1-2分 |

### ⚠️ 关键警告：常见扣分项（阅卷顾问核实）

1. **粉笔风格"先写习近平要求"**：10分概括题先写"习近平总书记强调XX"——阅卷场上是**扣分项**，不是加分项
2. **过度拔高**：概括题不需要升华到"时代意义""战略价值"
3. **上位词替代**：写"设计独特"不如写"提篮拱桥"

### 对策题评分标准模板（20-25分）

**校准要点**：
- 问题部分：每条问题1-2分，必须用**材料原文关键词**描述问题
- 对策部分：每条对策2-3分
  - 针对性：是否针对材料中提到的具体问题（占1分）
  - 可行性：是否有具体动作/措施（占1分）
  - 层次性：是否有逻辑顺序（占1分）
- **行政执法类对策评分更"实"**：需要写出**具体动作**（绿色通道、免申即享、家访式上门），成效要可证（纾困解难、获得感、少跑腿），不鼓励抽象升华

## 第二部分：按档给分题评分细则

### ⚠️ 核心原则（阅卷顾问校准）

> **大作文必须采用"档内浮动制"，绝对不能用"按点给分"方式**
> 
> 阅卷实际流程 = **8秒定档 + 30秒微调**
> 
> 阅卷者不是逐条找分，而是：先看标题和开头判断是否扣题→快速扫读各段首句判断分论点→扫读论据→给出档位判断

### 大作文评分操作流程（校准版）

```
步骤1（8秒定档——快速判断）：
  ✅ 看标题 → 是否扣题、是否有思想性
  ✅ 看开头 → 是否迅速入题、有无明确观点
  ✅ 看每段首句 → 判断分论点是否清晰、有无逻辑关系
  ✅ 看结尾 → 是否有呼应和升华

步骤2（30秒微调——精调分数档）：
  ✅ 看论据来源多样性 → 是否内外结合（材料外论据是隐性加分项）
  ✅ 看语言表达 → 是否有文采、是否通顺
  ✅ 看结构 → 是否严谨（并列/递进/总分总）

步骤3（扣分项检查）：
  ✅ 是否偏离主题 → 降档
  ✅ 是否大量抄袭材料 → 降档
  ✅ 字数是否达标 → 扣分
  ✅ 卷面是否整洁 → 扣分

关键：档位判定标准要清晰，而不是追求分值精确到几分
```

### 大作文35分制评分细则（国考——校准版）

| 档次 | 分数区间 | 核心判断标准 |
|------|---------|-------------|
| **一类上** | 32-35 | 立意深刻+结构有递进+论据独特（材料外）+语言有力 |
| **一类下** | 28-31 | 扣题+结构完整+语言流畅+论证充分（材料内为主+适当外部） |
| **二类上** | 24-27 | 扣题但分论点平行无递进/论据全抄材料/语言通顺但平淡 |
| **二类下** | 20-23 | 扣题但结构混乱/分论点不清晰 |
| **三类** | 14-19 | 部分跑题/套模板/内容空洞 |
| **四类** | 0-13 | 完全跑题/空白/抄袭占80%+ |

**校准要点**：
- 一类文上线从35降为35（上限不变，但下限收窄）
- **论据独特性**是隐性加分项——使用独特论据（如张骞凿空西域、鲸落生态）比全用材料论据（如玉陵湖大桥、凤凰河）高半个档到一档
- "论据来源多样性"应作为隐性标准，虽不写入公开细则但评分员训练时应强调

### 大作文40分制评分细则（江苏——校准版）

| 档次 | 分数区间 | 核心判断标准 |
|------|---------|-------------|
| **一类上** | 36-40 | 立意深刻+结构递进+论据独特+语言出彩 |
| **一类下** | 31-35 | 扣题+结构完整+语言流畅+论证充分 |
| **二类上** | 27-30 | 扣题但分论点平行/论据全抄材料 |
| **二类下** | 23-26 | 扣题但结构混乱 |
| **三类** | 14-22 | 部分跑题/套模板 |
| **四类** | 0-13 | 完全跑题 |

### ⚠️ 江苏大作文特殊结构期待

江苏阅卷者期待答案呼应题目隐含的结构。例如：
- 2024江苏A卷大作文，高分答案按**"党员干部→少年儿童→社会大众"**三分法组织
- 说明分论点设置需从题目中提取结构线索，不能随意并列

### 扣分细则

| 扣分项 | 扣分幅度 |
|--------|---------|
| 标题缺失 | -2分 |
| 字数不足（每少50字） | -1分 |
| 字数少于600字 | 直接进入三/四类 |
| 卷面涂改严重 | -1至-3分 |
| 错别字（每3个） | -1分 |
| 明显抄袭给定材料 | 降一档处理 |

## 第三部分：混合型题评分细则

### 应用文评分标准模板

**校准要点**：应用文采用**格式分+内容分+语言分三分法**

#### 30分制（如国考行政执法类应用文，以2022行政执法第5题"公开信"为例）

| 评分维度 | 分值 | 具体标准 |
|---------|------|---------|
| **格式分** | 4分 | 标题+称谓+落款+日期，缺一项扣1分 |
| **内容分** | 20分 | 观点态度(6)+回应全面性(8)+措施可行性(6) |
| **语言分** | 6分 | 语气得体(3)+身份感(3) |

#### 20分制（普通应用文）

| 评分维度 | 分值 | 具体标准 |
|---------|------|---------|
| **格式分** | 3分 | 标题、称谓、落款等关键格式要素是否完整 |
| **内容分** | 12分 | 材料关键信息是否全面覆盖（原文关键词采分） |
| **语言分** | 5分 | 是否符合文体要求、语气是否得体 |

**语言得体特别提醒**：
- 公开信/倡议书类语气要体现身份感——不是"教育"群众，而是"沟通"群众
- ❌ 错误示例："成由勤俭败由奢"（像在教育群众，语气不当）
- ✅ 正确示例："万事开头难，但改进工作永无止境"（语气最真实）

#### 常见文体格式要点

| 文体 | 格式要求 | 语言风格 |
|------|---------|---------|
| 展板文稿 | 有标题，分段落，无固定称谓 | 生动形象，有感染力 |
| 简报/简讯 | 标题+导语+正文，含时间地点事件要素 | 简洁明了，要素齐全 |
| 调研报告提纲 | 题目+背景+问题+建议的结构 | 客观严谨 |
| 宣传稿 | 标题+正文+号召结尾 | 有感染力，有动员性 |
| 发言稿 | 称谓+开场白+正文+结束语 | 口语化但正式 |
| 公开信 | 标题+称谓+正文+落款+日期 | 语气真诚得体，有身份感 |

### 综合分析题评分标准模板

#### 国考综合分析题（10-15分制）

| 评分维度 | 分值 | 一类（8-10分） | 二类（5-7分） | 三类（2-4分） |
|---------|------|---------------|--------------|--------------|
| 观点准确 | 3分 | 准确理解句子深层含义 | 理解基本正确 | 理解偏差 |
| 分析透彻 | 4分 | 结合材料多角度分析 | 有分析但较浅 | 浮于表面/空谈 |
| 逻辑清晰 | 2分 | 表态→解释→分析→总结 | 基本有逻辑 | 逻辑混乱 |
| 语言精炼 | 1分 | 表达精准简洁 | 基本通顺 | 语病较多 |

#### ⚠️ 江苏综合分析题（15-20分制——校准版）

**必须设"观点分"作为前置门槛**：

| 评分维度 | 分值 | 说明 |
|---------|------|------|
| **观点分** | 4-5分 | **前置门槛**。观点是否正确明确？错则直接降档 |
| 分析透彻 | 8-10分 | 是否结合材料分析原因/表现/影响 |
| 逻辑清晰 | 3分 | 层次是否分明 |
| 语言表达 | 3分 | 是否通顺、精炼 |

**执行规则**：
1. 先评观点分——如果观点错误或者模糊，**直接降一档**
2. 观点正确后再评分析深度
3. 例如2024江苏A卷第2题（阅读推广vs推销），观点判断错则整题最多得一半分

**综合分析题标准结构**：
```
第一层（表态+解释）：这句话/现象的意思是……（观点要明确）
第二层（分析）：具体来说……（结合材料分析原因/表现/影响）
第三层（总结）：因此，……（总结升华）
```

## 第四部分：行政执法卷专项评分标准

### 适用范围
- 国考行政执法卷（2022年起）
- 江苏B卷（行政执法类）

### 核心原则：评分要更"实"

| 维度 | 副省级/综合类 | 行政执法类 |
|------|-------------|-----------|
| **概括题采分** | 原文关键词+适当概括 | **只认具体动作和具体成效** |
| **对策评分** | 策略性、方向性可行即可 | **必须写出具体动作**（绿色通道、免申即享） |
| **成效描述** | 可适当抽象 | **必须可证**（纾困解难、获得感、少跑腿） |
| **语言风格** | 可有一定高度 | **不鼓励抽象升华**，越具体越好 |
| **大作文主题** | 可上升到治理现代化 | 贴近执法实务、法治政府建设 |

### 行政执法类题目采分点设置建议

**示例：2022国考行政执法第1题（惠企政策）**

| 采分要点 | 要求 |
|---------|------|
| 具体做法 | 绿色通道、免申即享、家访式上门——**必须是原文中的具体动作** |
| 具体成效 | 纾困解难、获得感、少跑腿——**成效必须可验证** |
| 不采分内容 | 优化营商环境、提升治理水平（太抽象，不给分） |

## 第五部分：题型特定评分要点

### 国考特有题型

**语句理解题**（10-15分）：
- 不能只做字面解释，必须结合材料上下文
- 需要有"为什么"的分析层次
- 结尾可以适度引申但不能过度发挥

**"启示类"综合分析**（15分）：
- 需要从案例中提炼出可推广的经验
- 启示不能太具体（否则失去普适性）
- 也不能太抽象（否则失去操作性）

### 江苏特有题型

**评析题**（15分）：
- 必须明确表态（肯定/否定/辩证看待）——这是观点分前置
- 既要分析合理性也要指出局限性
- 最后要有正确导向的总结

**简讯写作**（20分）：
- 必须包含5W要素（时间、地点、人物、事件、意义）
- 语言简洁，突出亮点
- 字数控制严格，超出扣分明显

## 第六部分：评分一致性保障

### 双评规则（建议）

- 大作文（35-40分）和综合分析题（10-15分）：每份试卷由2位评卷员独立评分
- 评分差超过该题总分20%时（如大作文差7分以上）：交由组长评定
- 其他题型：可由1位评卷员评分，但需每日抽查5%进行一致性检验

### 评分员训练要点

1. **校准训练**：每位评分员先独立评30份预试卷，与标准答案比对，确保对采分点理解一致
2. **边评边校准**：每评50份做一次一致性检验
3. **标杆卷**：每档保留3-5份标杆卷，供评分员参考
4. **"论据独特性"共识**：评分员需对"材料外论据加分"达成一致标准（避免主观差异）

### 机构答案参考价值排序（阅卷顾问建议）

| 优先级 | 机构/来源 | 理由 |
|-------|----------|------|
| ★★★★★ | 一眉巫师 | 唯一标注分值和评分关键词的答案，编制者大概率阅过卷 |
| ★★★★ | 上岸村批改 | 每道题给了明确的批改标准和分值分配 |
| ★★★ | 某笔/某公 | 关键词踩得准，结构规范，但无分值标注 |
| ★★ | 站长/华图 | 分析较深但有时过度发挥 |
| ★ | 粉笔先申夺人 | 常见过度拔高（10分概括题先写习近平要求），参考时需过滤 |
| 仅供参考 | XHS/个人答案 | 差异大，需交叉验证后使用 |

### 异常答案处理

| 异常类型 | 处理方式 |
|---------|---------|
| 观点明显偏离主流价值观 | 标记、上报、按零分处理 |
| 大作文全文抄袭材料 | 进入三类以下 |
| 空白卷或完全答非所问 | 零分 |
| 字迹完全无法辨认 | 尝试辨认后仍无法确认的，按保守估分 |
