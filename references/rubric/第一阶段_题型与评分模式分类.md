# 第一阶段：题型与评分模式分类（国考 & 江苏，2014-2025）

## 一、总览：两考命题格局

### 国考申论（副省级/地市级/行政执法）

| 特征 | 具体描述 |
|------|---------|
| 题量 | 5道题（近年稳定，早年4道） |
| 时限 | 180分钟 |
| 总分 | 100分 |
| 大作文分值 | 35分（近5年稳定） |
| 材料字数 | 6000-8000字 |

**典型结构**（2025副省为例）：
1. 概括归纳（15分）— 按点给分
2. 语句理解（10分）— 按档给分/混合
3. 应用文写作（20分）— 混合型（要点+整体评价）
4. 问题+对策（20分）— 按点给分
5. 大作文（35分）— 按档给分

### 江苏申论（A/B/C卷）

| 特征 | 具体描述 |
|------|---------|
| 题量 | 4道题（稳定） |
| 时限 | 150分钟 |
| 总分 | 100分 |
| 大作文分值 | 40分 |
| 材料字数 | 5000-7000字 |

**典型结构**（2025 A卷为例）：
1. 归纳概括（20分）— 按点给分
2. 分析理解/评析（15-20分）— 按档给分/混合
3. 应用文写作（20-25分）— 混合型
4. 大作文（40分）— 按档给分

## 二、按评分模式的三种题型分类

### A类：按点给分题

**特征**：有明确的采分点（关键词/短语），答到即给分，漏点扣分。阅卷速度快，标准化程度高。

#### 1. 概括归纳类

国考典型题目：
- 2014副省第1题："给定资料2揭示了当前社会心理方面存在的若干'缺失'，请予以归纳概括"（10分，150字）
- 2020副省第1题："概括L省在人才的政治引领方面的主要举措"（10分，200字）
- 2025副省第1题："谈谈三条'黄河'分别指的是什么，并说明它们是如何协同发挥作用的"（15分，350字）

江苏典型题目：
- 2025A第1题："用一段话对文化创意与地方旅游深度融合显著成效进行归纳概括"（20分，250字）
- 2025B第1题："对一些地方'花式'普法的做法及其成效加以归纳概括"（20分，250字）
- 2020A第1题："归纳概括我国互联网在不同发展阶段的特点"（20分，250字）

**采分点规律**：
- 来源：90%直接来自给定材料（原文关键词提炼）
- 每条要点的字数通常控制在15-30字
- 答案条数一般在3-6条
- 核心动词、关键名词是区分采分点的标志

**评分粒度**：
- 每个采分点2-3分
- 语言表述不要求完全一致，但核心语义必须匹配
- 字数超出酌情扣分（通常扣1-2分）

#### 2. 提出对策类（单独出题或与问题捆绑）

国考典型题目：
- 2025副省第4题："梳理青溪县数据标注企业发展中面临的问题，并提出进一步推动该县数据标注产业发展的建议"（20分，400字）
- 2020副省第3题："拟定脱贫攻坚队下一步工作的主要任务及措施"（20分，500字）

江苏典型题目：
- 2025B第3题："对'卫片执法'存在的问题进行梳理并提出相应的解决对策"（25分，350字）

**采分点规律**：
- 问题部分：每条问题2分，覆盖3-4个方面
- 对策部分：每条对策2-3分，需有针对性（与问题对应）
- 对策需体现可行性（具体做法而非空泛表态）
- 国考倾向"问题+建议"捆绑式，江苏有明显"问题+对策"分列式

---

### B类：按档给分题

**特征**：无固定标准答案，按内容档次整体评分。阅卷难度大，需依据档次锚定描述判断。

#### 大作文（议论文）

国考：分值35分，要求1000-1200字
江苏：分值40分，要求1000字左右

**典型题目**：
- 2025副省第5题："事物的劣势在特定条件下可以转化为优势……请你对此进行深入思考，参考给定资料，联系实际，自选角度，自拟题目，写一篇文章"（35分）
- 2020副省第5题：以相关主题写一篇议论文（35分）
- 2025江苏A第4题："文化创新赋能新质生产力，文化创造助力奋进新征程"为主题（40分）
- 2025江苏B第4题："贴心服务提升行政执法质效，为民理念激发社会发展活力"为主题（40分）

**分档标准（通用框架）**：

| 档次 | 分值 | 核心特征 |
|------|------|---------|
| 一类（上） | 31-35（国考）/36-40（江苏） | 观点鲜明深刻，论据充实，结构严谨，语言流畅有文采 |
| 一类（下） | 26-30（国考）/30-35（江苏） | 观点明确，论据较充实，结构完整，语言通顺 |
| 二类（上） | 21-25（国考）/24-29（江苏） | 观点基本明确，论据较充分，结构基本完整，语言基本通顺 |
| 二类（下） | 16-20（国考）/18-23（江苏） | 观点不够明确，论据单薄，结构不够完整，语病较多 |
| 三类 | 11-15（国考）/10-17（江苏） | 偏离题意，内容空洞，结构混乱，语言不通顺 |
| 四类 | 0-10（国考）/0-9（江苏） | 完全跑题，抄袭材料，字数严重不足 |

---

### C类：混合型（要点+整体评价）

**特征**：既有明确的采分点/格式要点，又有整体印象分（语言表达、逻辑结构等）。应用文是典型代表。

#### 应用文/贯彻执行类

国考典型题目：
- 2025副省第3题："为展板拟写一篇文稿，宣传介绍粮仓的'前世今生'"（20分，400字）
- 2020副省第4题："撰写调研报告中'问题'与'建议'这两部分内容的提纲"（25分，500字）

江苏典型题目：
- 2025A第3题："就'扬州市第三届大运河青年文创产业合作大会'的举行，写一则简讯"（20分，350字左右）
- 2020A第3题："拟定'小巷总理在基层'板块的展览内容提纲"（25分，350字左右）

**评分构成（通用模型）**：

| 维度 | 权重 | 说明 |
|------|------|------|
| 内容要点 | 60% | 材料中的关键信息是否全面覆盖 |
| 格式规范 | 10% | 文体格式是否正确（如简讯的标题、时间要素等） |
| 逻辑结构 | 15% | 层次是否清晰，过渡是否自然 |
| 语言表达 | 15% | 是否符合文体要求，是否生动/规范 |

#### 综合分析类（语句理解、评析）

国考典型题目：
- 2025副省第2题："谈谈你对划线句子'只有慢慢发展，慢慢成熟……不是产业，竟是产业'的理解"（10分，300字）
- 2014副省第2题："谈谈'预先失败'这一概念的含义"（10分，200字）

江苏典型题目：
- 2025A第2题："就如何让'流量经济'健康发展，谈谈你的理解和认识"（20分，300字左右）
- 2025B第2题："谈谈对'体检式监管，服务型执法'这一执法新模式的理解和认识"（15分，300字左右）
- 2020A第2题："对张先生与小胡的职业观分别进行评析"（15分，250字左右）

**评分构成**：

| 维度 | 权重 | 说明 |
|------|------|------|
| 观点明确（表态） | 20% | 是否准确判断、表明立场 |
| 分析透彻（理由） | 50% | 是否结合材料分析原因/表现/影响 |
| 逻辑清晰 | 15% | 层次是否分明 |
| 语言准确 | 15% | 是否通顺、准确 |

## 三、国考与江苏题型偏好差异

| 对比维度 | 国考 | 江苏 |
|---------|------|------|
| **题量** | 5道，更丰富 | 4道，更精炼 |
| **大作文占比** | 35%（近年） | 40%（稳定） |
| **大作文分值** | 35分 | 40分 |
| **综合分析** | 更常见（如语句理解） | 也常见（理解/评析），侧重社会现象评析 |
| **应用文文体** | 文稿/提纲/简报等 | 简讯/提纲/展览内容等 |
| **概括题分值** | 10-15分，字数150-350字 | 20分，字数250字 |
| **对策题特色** | 常与问题捆绑（概括+对策） | 单独出对策题（问题+对策分列） |
| **题材偏好** | 宏观治理/科技创新/文化自信/社会治理 | 法治政府/经济发展/文化创新/民生服务 |
| **材料风格** | 案例+理论+政策 | 案例为主，贴近基层实务 |
| **命题稳定性** | 近年趋稳，但题型有微调 | 高度稳定，四题结构固化 |
| **区分度策略** | 通过综合分析题区分 | 通过大作文（40分）区分 |

### 关键发现

1. **国考更注重"深度分析能力"**：综合分析题的出题频率和难度均高于江苏，需要考生从材料中提取隐含逻辑。

2. **江苏更注重"实务应用能力"**：应用文和概括题分值更高，且更贴近基层政府工作实际（如简讯、提纲等）。

3. **国考2014→2025的趋势变化**：
   - 早期的概括+分析组合（如2014副省第1/2题各10分）→近年增加应用文比重
   - 大作文从40分降为35分（约2019年后稳定）
   - 2022年后增加行政执法卷，题型更实务化

4. **江苏2019→2025的趋势变化**：
   - 四题结构几乎不变：概括(20)+分析(15-20)+应用文(20-25)+大作文(40)
   - A/B/C卷题型结构一致，材料主题不同（A类综合管理、B类行政执法、C类乡镇基层）
   - 分值分配极度稳定
