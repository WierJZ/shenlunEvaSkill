# 第三阶段：分档锚定标准

## 一、大作文分档锚定标准（国考35分制 / 江苏40分制）

### 一类文（国考28-35分 / 江苏32-40分）

**【中心论点】**
- 观点鲜明、深刻，准确抓住材料核心立意（如"主观能动性"这一命题核心）
- 能在材料基础上有所升华，体现辩证思维和理论高度

**【结构逻辑】**
- 结构严谨，层次分明
- 总-分-总结构清晰，分论点之间有内在逻辑关系（并列/递进/辩证）
- 过渡自然，论述环环相扣

**【内容论证】**
- 论据充实，材料内案例运用恰当
- 能结合材料外的事实例证（如华为、塞罕坝、乡村振兴等）
- 论证方法多样（理论论证+事实论证+对比论证）

**【语言表达】**
- 语言流畅，有文采
- 能运用恰当的修辞和引证（如名言名句）
- 用词精准，表达凝练

**【一类文典型特征识别】**
1. 标题有思想性，不是简单照抄主题（如"颓波转棹，志在长风：以主观能动化劣为优" vs "发挥主观能动性"）
2. 开头有引子且迅速切入主题
3. 每个分论点有理论支撑+案例佐证
4. 结尾有升华，但不大而空

### 二类文（国考21-27分 / 江苏24-31分）

**【二类上 国考25-27分/江苏28-31分】**
- 观点明确但不够深刻——正确理解了"劣势转优势"依赖"主观能动性"，但停留在"是什么"层面，缺乏"为什么"的深入分析
- 结构完整，有时间顺序或并列结构，但缺少递进深度
- 论据较充实，使用材料案例充分，但外部案例较少或运用生硬
- 语言通顺，偶有亮点但不够稳定

**【二类下 国考21-24分/江苏24-27分】**
- 观点基本明确，但略显模糊或不够聚焦
- 结构基本完整，但分论点之间缺乏逻辑关联（随意并列）
- 论据以材料案例为主，缺少外部拓展
- 语言基本通顺，但平铺直叙，缺乏文采

**【二类文典型失分点】**
1. 分论点设置随意，三个分论点之间没有逻辑关系
2. 通篇复述材料案例，缺少独立思考和升华
3. 开头冗长，迟迟不入题
4. 语言口语化或官方套话堆砌

### 三类文（国考11-20分 / 江苏10-23分）

**【三类上 国考16-20分/江苏18-23分】**
- 观点不够明确或部分偏离题意（如只写"劣势转优势"但没写"主观能动性"）
- 结构不够完整，有明显的逻辑断层
- 论据单薄，大量抄袭材料原文
- 语言不够通顺，语病较多

**【三类下 国考11-15分/江苏10-17分】**
- 严重偏离题意（如主题是A但写了B）
- 结构混乱，缺乏基本框架
- 内容空洞，或大量抄袭给定材料
- 语言不通顺，影响阅读

### 四类文（国考0-10分 / 江苏0-9分）

- 完全跑题
- 抄袭给定材料占全文80%以上
- 字数严重不足（少于600字）
- 观点反动或价值观严重偏差
- 未完成写作

## 二、应用文分档锚定标准

### 一类文（16-20分 / 以20分制为例）

- 内容要点：材料的关键信息全面覆盖，无遗漏
- 格式规范：文体格式正确（如简报有导语、正文、结尾；简讯有事件要素）
- 结构逻辑：层次清晰，过渡自然，逻辑性强
- 语言表达：符合文体要求（生动/简洁/正式），表达流畅

### 二类文（11-15分）

- 内容要点：覆盖大部分要点，遗漏1-2个次要要点
- 格式规范：格式基本正确但有小瑕疵
- 结构逻辑：层次清楚但欠严密
- 语言表达：基本符合文体要求但缺乏亮点

### 三类文（6-10分）

- 内容要点：遗漏多项要点或提取错误
- 格式规范：格式错误较多或不遵循文体要求
- 结构逻辑：层次不清，逻辑混乱
- 语言表达：不符合文体要求，语病较多

### 四类文（0-5分）

- 内容严重偏离材料
- 文体完全错误
- 字数严重不足或篇幅远超要求

## 三、综合分析题（语句理解类）分档锚定

### 一类文（8-10分 / 以10分制为例）

- 观点准确（正确理解句子含义）
- 分析透彻（从上下文、材料和时代背景多角度分析）
- 逻辑清晰（表态→解释→分析→总结的结构完整）
- 语言精炼

**典型一档答案特征**：
```
这句话的意思是……（准确解释）+ 这背后反映了……（深层含义）+ 
在徐庄改造中表现为……（结合材料具体分析）+ 因此，启示我们……（总结升华）
```

### 二类文（5-7分）

- 观点基本准确，但理解不够深入
- 有分析但不够透彻，停留在表面
- 逻辑基本清晰但结构有欠缺
- 语言基本通顺

### 三类文（2-4分）

- 理解有偏差或只理解字面意思
- 分析肤浅或脱离材料
- 逻辑混乱
- 语言不通顺

### 四类文（0-1分）

- 完全错误理解
- 答非所问

## 四、各档次之间的关键区分线

### 大作文区分的"一句话法则"

| 区分点 | 一类文 | 二类文 | 三类文 |
|--------|--------|--------|--------|
| **高度** | 有理论高度和思想深度 | 观点正确但平庸 | 观点模糊或有偏差 |
| **结构** | 分论点有逻辑递进 | 分论点并列无递进 | 结构混乱或缺失 |
| **论据** | 材料内+材料外结合 | 以材料内为主 | 大量抄袭材料 |
| **语言** | 有文采/有亮点句 | 通顺但平淡 | 不通顺或有语病 |
| **卷面** | 整洁无错字 | 基本整洁 | 涂改较多 |

### 应用文区分的"三看原则"

1. **看要点全不全**（决定是否进入一档/二档）
2. **看格式对不对**（在要点基础上加减分）
3. **看语言好不好**（在同一档次内区分上下）

### 概括题区分的"两个关键"

1. **全面性**（采分点覆盖度）——占总分的70%
2. **条理性**（分类归纳能力）——占总分的20%
3. **语言准确性**（用词是否精准）——占总分的10%
