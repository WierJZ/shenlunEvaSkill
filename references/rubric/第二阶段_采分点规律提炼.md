# 第二阶段：采分点规律提炼

基于28份国考和21份江苏多机构答案对比数据的系统分析。

---

## 一、从"多机构答案最大公约数"看高频采分点

### 方法论

对同一道题的多家机构答案，分析三个层次：
1. **钢性采分点**：出现在80%以上机构答案中的关键词/短语 → 高概率真实采分点
2. **弹性采分点**：出现在40%-80%机构答案中 → 可能是备选采分点或加分项
3. **机构独有内容**：仅1-2家机构出现 → 大概率非真实采分点，为特色文采加成

### 实例拆解：2025国考副省第1题（15分）

**题目**："给定资料1提到了三条'黄河'，请你谈谈这三条'黄河'分别指的是什么，并说明它们是如何协同发挥作用的。"

**25家机构答案的共识分析**：

| 采分点 | 出现率 | 判断 |
|--------|--------|------|
| "原型黄河"（也称"实体黄河/自然黄河"） | 100% | ★钢性采分点 |
| "数字孪生黄河"（也称"数字黄河"） | 96% | ★钢性采分点 |
| "模型黄河"（也称"模拟黄河"） | 100% | ★钢性采分点 |
| 数字孪生黄河=把原型黄河"装进"计算机 | 92% | ★钢性采分点 |
| 模型黄河=把黄河"放进"实验室 | 88% | ★钢性采分点 |
| 原型黄河提供动态数据/是基础 | 84% | ★钢性采分点 |
| 数字孪生黄河具有"四预"功能（预报、预警、预演、预案） | 80% | ★钢性采分点 |
| 数字孪生黄河形成"2+N"智能业务应用体系 | 72% | ★弹性采分点 |
| 实现五级联防联动 | 68% | ★弹性采分点 |
| 河务通App汇集海量数据 | 64% | ★弹性采分点 |
| "智慧石头"24小时实时预警 | 48% | 弹性采分点 |
| 防汛会商预演系统实现一屏掌控 | 56% | 弹性采分点 |
| 远程巡航监测发现处置违法行为 | 40% | 弹性采分点 |
| 模型黄河提供物理参数 | 76% | ★弹性采分点 |
| 形成自主知识产权的黄河模型架构体系 | 52% | 弹性采分点 |
| 自主研发多模型一体、安全可控模型平台 | 36% | 机构特色（注意区分） |

**关键词"旗帜公考"和"新途径"的异同**：
- 这两家将"智慧黄河"作为第一条"黄河"的表述——与其他所有机构不同
- 说明"智慧黄河"大概率**不是**标准采分点，而是这两家机构的独特表述
- 其他所有23家机构均使用"原型黄河/实体黄河/自然黄河"
- 结论：采分点必定是"原型黄河"，而非"智慧黄河"

### 实例拆解：2025国考副省第2题（10分）

**"只有慢慢发展，慢慢成熟，蓦然回首才会发现：不是产业，竟是产业"的理解**

**25家机构答案的共识分析**：

| 采分点 | 出现率 | 判断 |
|--------|--------|------|
| 不应急功近利/急于求成 | 96% | ★钢性采分点 |
| 在时间中慢慢沉淀/自然养成 | 92% | ★钢性采分点 |
| 借鉴"竟是山"的传统建园理念 | 84% | ★钢性采分点 |
| 涵养性情、寄托情怀、人与情景交融 | 80% | ★钢性采分点 |
| 避免成为"网红打卡地"转瞬即逝 | 76% | ★弹性采分点 |
| 依托鹜岛，三生相融（生态、生活、生产） | 68% | 弹性采分点 |
| 保留街区内在肌理，入驻多元业态 | 64% | 弹性采分点 |
| 整合解决方案，精细化运作 | 60% | 弹性采分点 |
| 把厚重历史变成当代语言 | 52% | 弹性采分点 |
| 规划升级产业园/设计追光博物馆 | 44% | 弹性采分点 |
| 打造诗意栖居的心灵家园 | 40% | 弹性采分点 |

**独家内容分析**：
- "坚持绿色、协调、可持续的发展理念"——仅粉笔出现，其他机构无→非采分点
- "徐庄在城市化进程中从富庶小镇变为脏乱差城中村"——仅东汇达出现→非采分点
- 各机构在"具体做法"部分差异最大→说明这部分是加分区域而非核心采分点

## 二、各题型采分点来源规律

### 按来源分类的三种采分点类型

| 类型 | 定义 | 占比 | 典型题型 |
|------|------|------|---------|
| **原文直接提取** | 材料中的原词原句，直接抄录即可得分 | 40-50% | 概括归纳题 |
| **概括提炼** | 需要将材料内容重新组织、分类、提炼 | 35-45% | 综合分析题、问题概括 |
| **引申推断** | 需基于材料进行逻辑推理和引申 | 10-20% | 对策建议、大作文论点 |

### 各题型的采分点来源明细

#### （一）概括归纳题

**来源分布**：
- 原文直接提取：60-70%
- 概括提炼：30-40%
- 引申推断：0-5%

**规律**：
- 要点几乎全部来自给定材料，极少需要自行发挥
- 高分关键不是"找不找得到"而是"找得全不全"
- 动词+名词的结构是最稳定的采分点形式
- 2025副省第1题"三条黄河"的采分点几乎全部为原文提取（"原型黄河""数字孪生黄河""模型黄河"在原文中均有明确出处）

**失分主因**：
1. 遗漏要点（最致命）
2. 超出字数（扣分）
3. 分类混乱（条理分扣减）

#### （二）综合分析题（语句理解/评析）

**来源分布**：
- 原文直接提取：20-30%
- 概括提炼：50-60%
- 引申推断：15-25%

**规律**：
- "表态+分析+总结"的三段式结构
- 核心观点须从材料中提炼，不能脱离材料自由发挥
- 理由部分需结合材料具体案例/数据
- 总结部分可以适度升华（这是区分档次的区域）

**失分主因**：
1. 观点判断错误（最致命）
2. 分析脱离材料空谈道理
3. 逻辑层次混乱

#### （三）提出对策题

**来源分布**：
- 原文直接提取：15-25%
- 概括提炼：40-50%
- 引申推断：30-40%

**规律**：
- 问题部分：几乎全部来自材料（原文+概括）
- 对策部分：部分来自材料中的"已有做法"（直接提取），部分需自行推导（引申推断）
- 高分对策需满足：针对性（针对问题）+可行性（具体可操作）+层次性（分主体/分阶段）

**实例（2025副省第4题）**：
- 材料中明确提到的问题：AI取代人工标注、门槛提高、人才不足、承接能力弱等——钢性采分点
- 材料中已有的对策思路：政府支持、东数西算、打造产业带——直接提取
- 需引申的对策：培训体系建设、差异化竞争战略等——引申推断

#### （四）应用文写作（混合型）

**来源分布**：
- 原文直接提取：40-50%
- 概括提炼：35-40%
- 引申推断：10-20%

**规律**：
- 内容要点：来自材料提取（前世今生的关键信息）
- 结构逻辑：需自行组织（时间顺序/空间顺序/逻辑顺序）
- 语言表达：需符合文体要求（简讯要简洁、展板要生动）
- 格式规范：需掌握常见文体格式

**实例（2025副省第3题"今州粮仓前世今生"展文稿）**：
- 25家机构答案都包含的核心信息（共识度100%）：
  - 建于20世纪50年代、占地136亩
  - 新中国成立后承担粮食储存重任
  - 20世纪末功能弱化、衰落、废弃
  - 修旧如旧、外部沧桑内部蝶变
  - 巨型铁质号角、"云间麦田"展厅、吸粮房变品茶空间、筒仓涂鸦
  - 成为"精神粮仓"

#### （五）大作文

**来源分布**：
- 原文直接提取：5-10%
- 概括提炼：30-40%
- 引申推断：50-60%

**规律**：
- 论点需从材料中提炼，但不能照搬材料
- 论据可结合材料案例+自身知识积累
- 语言表达、思想深度是区分档次的关键
- 标题、开头、结尾是阅卷重点区域

**实例（2025副省第5题"劣势转化为优势"）**：
- 材料中的案例：徐庄（慢发展）、今州粮仓（修旧如旧）、青溪县数据标注（借东风）
- 各机构的共同论点：发挥主观能动性
- 差异点：分论点设置不同（定力/创新/协同 vs 科技/文化/产业）

## 三、国考与江苏的采分点差异

| 对比维度 | 国考 | 江苏 |
|---------|------|------|
| **概括题原文出现率** | 60-70% | 70-80% |
| **对策引申比例** | 30-40% | 20-30% |
| **大作文结合材料度** | 需紧扣材料（35分） | 可适度发挥（40分） |
| **应用文格式要求** | 相对灵活 | 更规范（如简讯有固定要素） |
| **政策术语要求** | 较高（四预、2+N等） | 适中（侧重实务） |

**核心发现**：
- 江苏的采分点更"浅"——更多的原文直接提取
- 国考的采分点更"深"——需要更多的概括提炼和引申推断
- 因此，国考同分的水平通常略高于江苏同分（选拔性更强）
- 江苏更偏向"能不能找到"，国考更偏向"能不能理解"

## 四、识别"伪采分点"的技巧

多次出现≠采分点。以下特征的内容应谨慎判断：

1. **仅出现在同一家机构的不同年份答案中**：可能是该机构的固定风格，非真实采分点
2. **是修饰性语言而非实质信息**（如"生动体现了""精彩地展示了"）
3. **高度抽象的套话**（如"坚持以人民为中心"——过于通用，不太可能是具体采分点）
4. **与题干要求无关的方向**（如问"是什么"却在答"为什么"）

**建议**：以3家以上（粉笔、华图、中公、站长）都出现的核心语义为准，单一机构独有的内容标记为"机构特色"，不做采分点处理。
