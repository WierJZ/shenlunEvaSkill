## 依赖关系

本目录的产出建立在以下团队成员的工作基础之上：

## 使用建议

### 教学转化师本人
- **批改作业**：T6诊断模板 + T7失分分类 → 标准化快速诊断
- **1对1诊断**：T6诊断模板 + T10闭环流程 → 深入分析+改进计划
- **大班教学**：T8教学拆解 + T9教学框架 → 课程设计+课堂素材
- **考前冲刺**：T5学生参考指南 + T11思维训练方案 → 差缺补漏
- **机构答案教学**：产出7（学生版手册）→ 课堂分发，学生自学机构答案使用方法

### 给各角色的反馈
- **给评分架构师**：诊断模板v1.1已融入阅卷顾问的8项校准。建议评分细则v2.0采纳：①"上位概括=0分"规则 ②新增弹性采分点标识 ③增设"设问分"维度
- **给阅卷顾问**：失分模式分类已按你的15种模式校准对齐，请在产出#3中检查江苏分析题的"观点分"描述是否准确
- **给机构精析师**：产出7已合并你的主题对比+选机构指南，请检查"四看"原则中的省份分类是否准确。建议后续补充联考省份数据
