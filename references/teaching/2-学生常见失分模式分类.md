# 申论学生常见失分模式分类 v1.0

> 结合教学经验与阅卷顾问视角，将学生常见问题系统分类。每类提供典型症状、诊断方法和针对性处方。

## 二、第一类：阅读理解层面失分（根源性失分）

> 这是最根本、最致命的一类失分。阅读理解的偏差会导致后续所有环节出错——逻辑建错了、表达跑偏了、策略全白费。**这类失分的特点是"平时不注意，考试全暴露"**，因为阅读习惯的问题在平时练习中很容易被忽略。

### 模式1-1：「漏读症」——关键信息扫丢了

**【典型症状】**
- 答案只覆盖了材料中40-50%的要点
- 该写的采分点没写，不该写的废话写了一大堆
- 对照机构答案后发现："啊？这段还有这个信息？我跳过去了"

**【考场案例】**
```
题目：2025国考行政执法卷·第1题——概括A市促进高科技企业和新兴产业发展的主要做法
学生答案：只写了"成立科技成果转化专班"和"建设产业园区集群"2个点
标答对比：共需要5个点（成果转化、平台对接、园区集群、资金支持、人才汇聚）
失分：漏了"搭建工业互联网平台""国有投资平台投资""建设国际人才城"等3个核心点
```

**【根因分析】**
- **扫描式阅读**：眼睛扫过文字但大脑没处理，尤其是段落中间的"不起眼"信息
- **惯性忽略**：想当然地认为"这段不重要"，跳过不读
- **标记缺失**：手上没笔，不会在材料上做标记，读完整篇材料大脑一片空白

**【诊断自测】**
> 做完题后，用荧光笔在材料上圈出你提取的所有要点，数一数量。然后对照机构答案，如果你的要点数低于标准的70%，说明你有"漏读症"。

**【处方】强制性逐段标记法**
```
训练方案：
1. 材料阅读时，强制自己读一段停一下，用笔在本段旁边写"关键词：XXXX"
2. 每段至少提取1个要点，不准跳过任何一段
3. 读完所有段落后再回头检查：有没有哪段没写关键词？
4. 每天1篇材料精读训练，坚持7天
5. 自检标准：7天后能圈出机构答案90%以上的采分点
```

### 模式1-2：「误读症」——意思理解反了

**【典型症状】**
- 答案与材料主旨有明显偏差
- 把"问题"当成了"做法"，把"建议"当成了"现状"
- 老师看完会说："你好像读的是另一套题"

**【考场案例】**
```
题目：2023国考副省级·第2题——分析为什么说"窑洞修复过程也是村民从旁观者变参与者再到传承者"
学生错误示例："因为村民一开始不愿意修，后来觉得修了好看就参与了……"
正确理解：村民从"不理解专业方案"→"通过影像展认同价值"→"主动捐献参与"→"成为义务宣讲员"
典型误解：把"村民对修复材料的质疑"理解为"村民不愿意修"，忽略了"村民对窑洞的情感认同"
```

**【根因分析】**
- **带着预设读材料**：还没开始读就已经有了"答案"，读材料只是为了找证据支持自己的预设
- **混淆概念**：政策术语积累不够，把"修旧如旧"的文物保护理念理解为"省钱凑合"
- **忽视关联词**：没注意到"但是""然而""令人欣慰的是"等转折词，导致方向判断错

**【诊断自测】**
> 读完材料后，不急着写答案，先用一句话概括"这篇文章的核心意思是什么"。然后读一遍机构答案的"总体分析"部分，看你的概括是否一致。

**【处方】"三问审题法"**
```
训练方案：
1. 写完答案前，问自己三个问题：
   Q1：题目要我干什么？（概括？分析？提对策？）
   Q2：材料的主旨态度是正向还是负向？（表扬现状？批判问题？提出建议？）  
   Q3：我的第一句话和材料主旨方向一致吗？
2. 每天用3道真题的题目+材料练"三问"（不用写完整答案），训练7天
3. 自检标准：连错三问的题数降到10%以下
```

### 模式1-3：「发散症」——过度解读，脱离材料

**【典型症状】**
- 答案内容很丰富，但大半是自己"编"的
- 用上了很多热点素材、名言警句，但与材料无关
- 觉得自己答得"很有深度"，实际得分很低

**【考场案例】**
```
题目：概括A市促进高科技企业发展的主要做法
学生答案片段："A市积极响应国家创新驱动发展战略，以五大发展理念为引领……"
正确答案应该直接写："成立科技成果转化专班""搭建工业互联网平台"等具体做法
问题：学生写的是"评价"而不是"概括"，用自己的话"包装"了答案，但没有从材料中提取具体信息
```

**【根因分析】**
- **缺乏"材料意识"**：不知道申论答案=从材料里找答案，以为可以自由发挥
- **模板中毒**：背了大量万能开头和过渡句，不管题目是否需要都往上套
- **混淆题型**：把概括题当成了"写小作文"，不知道概括题考的是"精确提取"

**【诊断自测】**
> 写完答案后，逐句检查：这句话的信息有材料依据吗？如果没有，删掉。数一数删掉后还剩多少字——剩得越少，说明你"发散"得越厉害。

**【处方】"出处标签法"**
```
训练方案：
1. 每写完一条答案，在旁边标注出处："第_段第_行"
2. 如果标不出出处，说明这条信息不是来自材料
3. 不是来自材料的内容，直接删掉，没有例外
4. 每次练习前默念三遍："答案在材料里，不在我脑子里"
5. 训练量：5道概括题+5道分析题，每道题都必须标注出处
6. 自检标准：每句话都能标出材料出处
```

## 三、第二类：逻辑构建层面失分（结构性失分）

> 这类失分的特点是"要点都有了，但就是拿不到满分"。阅卷老师在快速阅卷时，首先看的是答案的结构——如果你的结构清晰，15秒就能给分；如果结构混乱，30秒也找不到得分点。

### 模式2-1：「一锅粥」——没有层次，全混在一起

**【典型症状】**
- 答案是一整段话，没有分点，没有序号
- 或者分了点，但各点之间在说同一件事
- 阅卷老师需要自己"拆解"才能找到采分点

**【考场还原（阅卷视角）】**
```
阅卷老师看到这样的答案：
"A市通过成立专班对接高校促进成果转化还通过互联网平台推动项目落地同时建设产业园区集群……"
→ 阅卷老师心里：这是在写什么？要点在哪？我自己来拆……（找得手酸）
→ 心理分已经扣了：结构分直接归零
对比：
"A市的主要做法：一、成果转化。成立专班，对接高校院所。二、平台对接。搭建工业互联网平台……"
→ 阅卷老师一眼看到5个要点，逐个核分
```

**【根因分析】**
- **动笔前没列提纲**：想到哪写到哪，写完点1写点5，再跳回点2
- **不会分类合并**：5个采分点混在一起，不会按主题归类
- **缺少序号意识**：觉得"加序号太机械"，不知道阅卷最喜欢"机械"的序号

**【处方】「强制结构化三步法」**
```
训练方案：
第一步：列骨架（3分钟）
  动笔前，在草稿纸上写：
  1. ____ (第一个要点)
  2. ____ (第二个要点)  
  3. ____ (第三个要点)
  ……
第二步：填血肉（按序写）
  按列好的顺序写，不准跳序，不准写序号之外的内容
第三步：核对修改
  写完后看一遍：各点之间是否有交叉重复？有的话合并

训练量：每次练习前必须列提纲，连续10次
自检标准：10次后，无需草稿也能自然分点
```

### 模式2-2：「缺胳膊少腿」——关键逻辑环节缺失

**【典型症状】**
- 综合分析题只有"对策"没有"分析"
- 应用文没有"问题描述"直接跳到"建议"
- 对策题只写"要做什么"没写"谁来做"和"怎么做"

**【考场案例】**
```
题目（综合分析题）：谈谈你对"窑洞修复让村民从旁观者变参与者再到传承者"的理解
学生答案：
"要让村民参与窑洞修复。一是加强宣传教育，二是组织参观学习，三是鼓励村民捐献……"
问题：题目要求"分析原因"，学生写了"对策"。跳过了"为什么"直接写"怎么办"。
这个错误直接把综合分析题做成了对策题，至少丢失60%的分数。
```

**【根因分析】**
- **模板依赖**：背了"对策模板"，不管什么题型都用对策框架套
- **不懂题型要求**：分不清"分析"和"对策"的区别
- **审题跳过环节**：题目要求"分析全面"，但只看到了"全面"没看到"分析"

**【处方】「题型对照表+强制框架」**
```
训练方案：
1. 建立自己的"题型-逻辑框架"对照表：
   - 概括题：①要点1 ②要点2 ③要点3……
   - 分析题：是什么→为什么→怎么办
   - 对策题：问题1→对策1，问题2→对策2
   - 应用文：背景/问题→意义/目的→具体内容→呼吁/要求
   - 大作文：开头→分论点1→分论点2→分论点3→结尾

2. 每次答题前，在草稿纸写出对应的框架，填空作答
3. 训练量：每种题型至少练5道，练到框架自动浮现
4. 自检标准：看到题型名称，1分钟内能说出该题型的逻辑框架
```

### 模式2-3：「两张皮」——标题和内容对不上

**【典型症状】**
- 小标题写得很漂亮："完善制度保障"——但下面写的是"加大资金投入"
- 或者写了小标题但下面的内容跟标题不相关

**【考场还原】**
```
学生答案：
"一、强化人才支撑。A市建设国际人才城，打造外国专家服务室……"
——这个标题和内容是对应的，没问题。
"二、加大资金投入。A市成立科技成果转化专班……"
——标题说"资金投入"但下面写的是"成果转化"。这叫"两张皮"。

阅卷老师看到这种情况，会认为你在"凑答案"——明显是先写了内容后加标题，标题是随便写的。
```

**【根因分析】**
- **先写内容后拟标题**：内容写完了才随便安一个标题上去
- **标题能力弱**：不会用自己的话概括一段内容的核心
- **贪图"好看"**：用了一个高级词汇（如"制度供给""顶层设计"），但自己都不清楚是什么意思

**【处方】「标题先行法」**
```
训练方案：
1. 写内容之前，先定标题——用动宾短语概括这段的核心
2. 写完标题后，围绕标题写内容（一句话检验：我写的内容能支撑这个标题吗？）
3. 标题要朴实准确，不要花哨——"加大资金投入"比"构建多层次金融支持体系"更安全
4. 训练量：做10道题，每题都必须先写标题再写内容
5. 自检标准：任何时候都能用3-5个字说清楚一段在讲什么
```

## 四、第三类：规范表达层面失分（呈现性失分）

> 这类失分最"不值"。明明理解了材料、答案要点也全了，但因为表达不规范被扣分。这类失分也是最容易通过训练解决的。

### 模式3-1：「口水话」——像在聊天不是在答题

**【典型症状】**
- "把东西做好""把事办好""让人满意"——太口语化
- 答案长度不短，但信息密度极低
- 把"这是非常重要的事情"写了300字，还不如写"意义重大"4个字

**【口语vs规范对照表】**
```
口语化表达                    →  规范表述
────────────────────────────────────────────────────
"把东西做好"                 →  "提升产品质量"
"让大家都满意"               →  "提升群众满意度"
"政府要管好"                 →  "加强政府监管力度"
"大家一起努力"               →  "形成多方协同合力"
"把这个事做好"               →  "完善工作机制，确保落实"
"叫大家来学"                 →  "开展专项培训"
"想办法解决"                 →  "制定针对性解决方案"
"不让坏人得逞"               →  "筑牢安全防线"
"多弄点钱"                   →  "拓宽资金筹措渠道"
"派好人"                     →  "优化人员配置"
```

**【根因分析】**
- **日常用语习惯**：生活中怎么说，考场上就怎么写
- **不会"翻译"**：脑子里想的是大白话，但没有转换成语体规范的能力
- **积累不够**：政策术语的词库太小

**【处方】「翻译练习法」**
```
训练方案：
1. 每天从机构答案中找5个规范表述，抄下来
2. 先用自己的大白话写一遍
3. 然后对照机构答案，分析"差在哪"
4. 建立自己的"口语→规范"对照本，每天复习
5. 训练量：每天5组，坚持14天，累计70组
6. 自检标准：看到一个口语表达，能在3秒内想到对应的规范表述
```

### 模式3-2：「车轱辘话」——同一意思反复说

**【典型症状】**
- 200字的答案，有效信息只有100字
- 翻来覆去说同一件事，"加强监管"说了3次
- 删除重复内容后字数直接减半

**【考场案例】**
```
学生答案（120字）：
"政府要加强对企业的监管力度，严格规范企业的经营行为。同时政府还要严格管理，
确保企业不违法经营。另外还要加大监督力度，让企业遵守法律法规。"

精简后（40字）：
"加强政府监管，规范企业经营行为，确保企业守法经营。"

多余的80字＝完全浪费的80字＝本来可以写更多要点但没地方写了
```

**【根因分析】**
- **思路不清**：不知道这段到底想说什么，边写边想
- **凑字数惯性**：字数不够就同义反复
- **不会概括**：不会用一句话说清楚三层意思

**【处方】「一字不多法」**
```
训练方案：
1. 写完后逐句检查：删掉这句话，意思变了吗？
   - 没变→删
   - 变了→保留
2. 尝试用最少的字表达最多的信息
3. 练习目标：200字的答案，信息量不低于180字（信息密度≥90%）
4. 训练量：每天做1道概括题，强制字数是题目要求的70%（练信息密度）
5. 自检标准：别人看完你的答案，找不出可以删的废话
```

### 模式3-3：「贴标签」——用词不准，术语用错

**【典型症状】**
- 用了高大上的词但用错了语境
- "供给侧结构性改革""放管服改革""营商环境"满天飞，但跟题目无关
- 只会用"加强""完善""推动""促进"四个万能动词

**【常见用词错误案例】**
```
❌ "加强科技创新发展" → ✅ "强化科技创新的核心地位"
❌ "群众有获得感" → ✅ "提升群众的获得感、幸福感、安全感"
❌ "建设绿水青山" → ✅ "践行'绿水青山就是金山银山'理念"
❌ "优化制度" → ✅ "完善制度供给，健全长效机制"
❌ "让企业有钱赚" → ✅ "优化营商环境，激发市场主体活力"

用错了还不如不用——阅卷老师会觉得你"不懂装懂"
```

**【根因分析】**
- **死记硬背**：背了一堆政策热词，但不知道每个词适用的场景
- **套路化表达**：无论什么话题都用同一套词
- **理解不深**：对政策术语的内涵一知半解

**【处方】「场景化积累法」**
```
训练方案：
1. 不要按"金句""好词好句"分类，按"使用场景"分类：
   - 社会治理类：______、______、______
   - 经济发展类：______、______、______
   - 生态环保类：______、______、______
   - 文化自信类：______、______、______
   - 乡村振兴类：______、______、______
   - 科技创新类：______、______、______
2. 每个词下面写2个例句，注明使用场景
3. 练习时强迫自己：每个场景只使用该场景下的词汇
4. 训练量：每周整理1个场景，每个场景积累5-8个规范表述
5. 自检标准：看到一个话题，能立刻说出该话题的核心"行话"3-5个
```

## 五、第四类：应试策略层面失分（操作性失分）

> 这类失分最"冤"——明明会做，但因为考试操作失误丢分。这类问题改起来最快，往往立竿见影。

### 模式4-1：「前松后紧」——时间分配失控

**【典型症状】**
- 前面的小题（特别是第1题）写得很仔细，用了计划时间的2倍
- 最后的大作文只剩20分钟，只能乱写
- 每次考完都说"如果时间够，我能再多考10分"

**【时间分配标准参考（150分钟）】**
```
题型示例（国考5道题）：
- 第1题（10分）：13-15分钟
- 第2题（15分）：18-20分钟
- 第3题（20分）：25分钟
- 第4题（20分）：25分钟
- 第5题（35分）：55-60分钟（含审题构思10分钟）
- 机动检查：10分钟

规律：每分≈1.5分钟（申论），大作文适当多留
```

**【根因分析】**
- **追求完美**：第1题非要写到"最好"才满意，不知道"够好就行"
- **不懂舍弃**：某个点想不出来就卡住不走，导致后面全崩
- **缺乏时间意识**：不会看表，不会按分值分配时间

**【处方】「肌肉记忆计时法」**
```
训练方案：
1. 每次练习必须计时，培养时间感
2. 严格执行"到点停笔"原则——不管写没写完
3. 记录每次各题的实际用时
4. 练习量：每周2套完整套题模拟，连续3周
5. 自检标准：能在规定时间内完成所有题目，且不留白
```

### 模式4-2：「字数失控」——要么不够、要么超出

**【典型症状】**
- 概括题要求250字，写了150字就写不出了（说明要点没找够）
- 应用文要求500字，写了600字还在写（说明不会精炼）
- 大作文要求1000-1200字，结果写了800字就结束了（说明分论点没展开）

**【合理字数区间参考】**
```
题目要求字数    合理区间     超出的后果
  150字        130-150字    超出不给分还可能倒扣
  250字        220-250字    超出倒扣或重点后移
  400字        380-400字    超出后内容不被评分
  500字        480-500字    超出部分阅卷不看
  800字        780-800字    超出扣结构分
 1000-1200字   1000-1200字  不足扣内容分，超出扣分
```

**【根因分析】**
- **不数格子**：写到哪算哪，完全不管字数
- **信息密度低**：有用的信息太少，只能用废话凑
- **要点不够**：字数不够的根本原因不是"写不出来"，而是"没找够要点"

**【处方】「定量写作法」**
```
训练方案：
1. 写之前先算：每题的标准字数÷要点数＝每个要点大约写多少字
2. 比如250字÷5个要点≈每个要点写50字
3. 写完后数一数——不超、不少
4. 训练量：每道题都做字数计算练习
5. 自检标准：看到题目能预估自己要写几个要点、每个要点大概多少字
```

### 模式4-3：「模板病」——生搬硬套被识破

**【典型症状】**
- 每次答案的开头都一样："随着经济社会的快速发展……"
- 对策题永远都是"加强宣传、完善制度、加大投入"三板斧
- 遇到材料的特殊情况不会灵活处理，模板一用，离题万里

**【被模板坑了的典型案例】**
```
题目：概括A市促进高科技企业发展的做法
模板式开头："随着我国经济进入新常态，创新驱动发展战略成为引领发展的第一动力……"
问题：题目要求"概括做法"，这个开头占了40字的位置写了1分都不值的内容
正确做法：直接写"A市的主要做法有：1.成立转化专班……"
模板开头的代价：浪费了40字的宝贵空间+给阅卷老师留下"模板化"的第一印象
```

**【根因分析】**
- **安全感依赖**：觉得模板能让自己"有话写"
- **思维懒惰**：不愿意每道题都重新构思
- **阅卷预判错误**：以为阅卷喜欢"规范"的套话，不知道阅卷最讨厌套话

**【处方】「去模板化三步骤」**
```
训练方案：
Step 1：识别你的模板
  回头看你最近10次练习，找出你每次都在用的"万能句"（如"随着……的发展"）
  把这些句子列成"我的模板清单"

Step 2：禁用清单
  以上清单的所有句子，在未来的练习中一律禁用
  每次想用的时候，问自己：不写这句话，会怎样？
  答案通常是：会更直接、更简洁、更得高分

Step 3：替代方案
  每个模板句准备一个"平实替代方案"
  "随着……的发展" → "当前，……"
  "具有重要意义" → "有助于……"
  "值得高度重视" → "要关注……"

训练量：至少10次练习完全不用模板
自检标准：别人看你的3次不同答案，看不出是同一个人的——说明去模板化了
```

### 模式4-4：「审题过急」——读题不超过30秒就动笔

**【典型症状】**
- 写了一半才发现：哦，原来题目要的是"建议"不是"分析"
- 写完才发现：题目要求"不超过250字"，已经写了400字
- 检查时才发现：题目让写"工作事项和工作内容"，自己只写了工作事项

**【审题检查清单】**
```
看到一道题，30秒内回答以下问题：
□ 这是什么题型？（概括/分析/对策/应用文/大作文）
□ 题目要求我干什么？（概括做法？分析原因？提出建议？）
□ 有没有特殊要求？（如"全面、准确、有条理"）
□ 字数要求是多少？
□ 指定了哪几段材料？
□ 有没有身份设定？（"假如你是……"）
□ 有没有格式要求？（应用文的标题/称谓/落款）
```

**【根因分析】**
- **考试焦虑**：总想"赶紧写"，怕写不完
- **读题习惯差**：看一半就觉得自己"懂了"
- **不核对**：写完了不回头看题目

**【处方】「30秒审题法」**
```
训练方案：
1. 每次拿到题目，强制自己30秒内不能动笔，只能读题
2. 30秒内完成审题检查清单（见上）
3. 如果30秒不够，继续读，读懂了再动笔
4. 动笔后每写完一段，看一眼题目，确认没偏
5. 写完最后一段，再看一次题目，确认所有要求都完成了
6. 训练量：每次练习严格执行，形成肌肉记忆
7. 自检标准：30秒内能回答审题清单上的所有问题
```

## 七、各失分模式的"高频伴侣"关系

> 学生的失分很少是单一的，通常多个模式同时出现。以下是常见的"失分组合"：

```
组合A：「漏读+一锅粥+字数不够」
  这种学生通常做题很"慢"，读得慢写得慢，导致信息抓不全、来不及整理
  → 处方：先解决阅读速度（限时扫描），再解决结构（列提纲）

组合B：「发散+口水话+超字数」
  这种学生通常"挺能写"，但写了太多没用的
  → 处方：先解决"材料意识"（出处标签法），再解决精炼（一字不多法）

组合C：「模板依赖+缺环节+贴标签」
  这种学生通常上过培训班，背了很多模板但不会灵活用
  → 处方：先去模板化（禁用清单），再重建题型的逻辑框架

组合D：「审题过急+时间失控+前松后紧」
  这种学生通常考试焦虑严重
  → 处方：先建立考试流程（审题计时+分题计时），再模拟考试环境脱敏
```
