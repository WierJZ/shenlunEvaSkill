## 二、场景A：批改作业场景

### 2.1 场景描述

**发生时间**：课后/线上
**核心任务**：对学生的单题答案进行评分+诊断+反馈
**时间预算**：每份作业15-20分钟（含写反馈）
**关键约束**：不能超过24小时反馈时间

### 2.2 标准工作流程（20分钟/份）

```
┌────── 15秒 ──────┐
│ 第一步：快速定档 │  ← 使用T6中的"15秒快速定档卡"
│  看审题+看前50字 │
│  +看结构+估档位  │
└────────┬─────────┘
         ▼
┌────── 3-5分钟 ───┐
│ 第二步：采分点核对│  ← 使用T1评分细则+T2阅卷校准
│  硬点逐条对照     │
│  弹性点三档判断   │
│  注意设问分陷阱   │
└────────┬─────────┘
         ▼
┌────── 3-5分钟 ───┐
│ 第三步：失分定位  │  ← 使用T7失分分类
│  匹配失分模式     │
│  追溯根源原因     │
│  标注"是能力还是  │
│  偶然失误"       │
└────────┬─────────┘
         ▼
┌────── 5分钟 ──────┐
│ 第四步：填写诊断   │  ← 使用T6诊断模板
│  填写总览+维度+   │
│  定位+原因+优先级  │
│  +练习方案        │
└────────┬─────────┘
         ▼
┌────── 2-3分钟 ────┐
│ 第五步：输出 + 发送│
│  检查+打印/发送    │
└────────────────────┘
```

### 2.3 批改时的"必须做"与"不要做"

**✅ 必须做：**

| 事项 | 原因 | 具体做法 |
|------|------|---------|
| 先看审题对不对 | 审题错=后面全错 | 快速判断：题型判断是否正确？要素是否完整？ |
| 先定档再微调 | 阅卷就是这样操作的 | 先给档，再在档内微调分数 |
| 区分硬点和弹性点 | 不同点扣分方式不同 | 硬点=是非判断，弹性点=分档判断 |
| 写一个"一句话诊断" | 学生最先看这个 | "你的主要问题是：______" |
| 每条失分点配改进方案 | 不配方案学生不知道怎么改 | 参见T6中的练习方案库 |

**❌ 不要做：**

| 事项 | 原因 | 替代做法 |
|------|------|---------|
| 不要写"加油""不错" | 无效反馈，浪费时间 | 写具体改进方案 |
| 不要一次指出10个问题 | 学生记不住，也不知道先改什么 | 只给1个P0 + 2个P1 |
| 不要用自己的标准评分 | 评分标准不是你的个人判断 | 对照T1评分细则 |
| 不要只看内容不看病根 | "漏了要点"是表象，"阅读方法不对"才是病根 | 使用T7追溯病因 |
| 不要超过24小时反馈 | 学生已经忘了解题思路 | 当天批改当天反馈 |

### 2.4 批改注意事项——阅卷顾问校准版

以下8项是从阅卷顾问第4期报告中提炼的**批改时必须注意**的事项：

```
⚠️ 校准1：上位概括=0分（非50-70%）
  如果学生用"设计精妙"代替"提篮拱桥"→ 不要给"部分分"，直接写0分
  批注："概括题不认上位词，要写原文关键词"

⚠️ 校准2：弹性采分点才是真正的分水岭
  如果学生硬点全中但弹性点差 → 分差可能在同类考生中拉开
  特别是综合分析题的"观点准确度"和应用文的"语言得体"，这两个弹性点弹性最大

⚠️ 校准3：设问分陷阱
  题目说"评析"但学生只分析没表态 → 扣分！
  批注时要指出："题目要求评析，你需要在开头亮出你的价值判断"

⚠️ 校准4：底线一类在双评中大概率跌回二类
  如果你判学生的答案属于"刚好够一类" → 提醒学生：
  "你的答案现在看起来是底线一类，但在真实双评中可能被二评打回二类上。
  要拿到稳一类，需要论据更独特/分析更深度。"

⚠️ 校准5：抄材料原文 vs 引用材料案例
  如果学生大段抄材料原文 → 降档处理
  如果学生用自己的话引述材料案例 → 正常给分
  关键区别：是"复制"还是"引用"

⚠️ 校准6：江苏A卷综合分析"观点先行"
  审题时要特别注意：学生是否在第一句话亮出观点
  没观点直接扣4-6分

⚠️ 校准7：应用文格式分因文体而异
  公开信：格式严格（标题+称谓+落款+日期）
  发言稿/简报/提纲：格式灵活（有标题即可）
  不要一刀切扣格式分

⚠️ 校准8：大作文分档比精确给分更重要
  35分的大作文，先判断是一类/二类/三类
  在档内再微调，不要跨档给分
  一类上上限调到30-32分（实际可达），33-35为理论区间
```

## 三、场景B：1对1诊断场景

### 3.1 场景描述

**发生时间**：面谈/视频通话
**核心任务**：和学生面对面分析问题、制定改进方案
**时间预算**：30-45分钟/次
**关键要求**：学生要"带走"明确的行动计划

### 3.2 1对1诊断流程（40分钟标准版）

```
┌── 前15分钟 ──┐
│  阅卷视角复盘  │  ← 核心：让学生站在阅卷者角度看自己的答案
│                │
│  Step 1:       │
│  "我们模拟一下 │
│  阅卷老师怎么  │
│  看你的答案"   │
│  ① 8秒快速印象│
│  ② 找采分点   │
│  ③ 数遗漏     │
│                │
│  老师示范：    │
│  "你看，阅卷   │
│  老师15秒内   │
│  看到的是____" │
└───────┬───────┘
        ▼
┌── 中间15分钟 ─┐
│  重点问题攻克  │  ← 核心：集中解决1-2个问题
│                │
│  选1个P0问题  │
│  ① 展示错例vs │
│     正例       │
│  ② 分析错在哪 │
│  ③ 现场改一遍 │
│  ④ 学生复述   │
│     "我哪里错了│
│     应该怎么改"│
│                │
│  注意：         │
│  不要讲超过    │
│  2个问题       │
└───────┬───────┘
        ▼
┌── 最后10分钟 ─┐
│  制定改进计划  │  ← 核心：写出具体可执行的方案
│                │
│  Step 1:       │
│  确定P0问题    │
│  Step 2:       │
│  约定训练任务  │
│  (具体到每天   │
│  做什么做多少) │
│  Step 3:       │
│  约定下次复查  │
│  时间           │
│  Step 4:       │
│  学生签字确认  │
└────────────────┘
```

### 3.3 1对1诊断中的"黄金提问"

> 这些提问比直接告诉学生"你错了"更有效——

**针对阅读理解问题：**
- "你读第_段的时候，脑子里在想什么？"
- "你为什么会跳过这个信息？是因为觉得它不重要，还是根本没看到？"
- "我们来玩个游戏：你读一句，告诉我这句在说什么。"

**针对逻辑构建问题：**
- "在动笔之前，你花了多长时间列提纲？"
- "如果你的答案只有3个要点，你选哪3个？"
- "这道题的逻辑框架应该是什么？（让学生自己说）"

**针对规范表达问题：**
- "如果只能用10个字概括这段，你怎么写？"
- "我们来做一个翻译练习：你刚才说的这句话，用规范表述怎么说？"
- "你看看机构答案里这个词，和你的词差距在哪？"

**针对应试策略问题：**
- "你在哪道题上花的时间最多？为什么？"
- "写到最后发现字数不够/超了，你是什么感觉？"
- "如果不限时间，你的答案会有什么不同？"

### 3.4 给学生的"诊断包"

1对1诊断结束后，学生应带走的材料：

```
📋 诊断包清单

□ 《诊断报告》（T6格式填写，一式两份）
□ 《改进计划》（签字版）
□ 《下次复诊通知》（具体到日期和时间）
□ 额外材料（从T8/T5中打印的相关内容）

改进计划模板：
  你的P0问题：____________________
  接下来___天，你每天要做：
  ① ____________________（___分钟）
  ② ____________________（___分钟）
  下次复查时间：___月___日
  复查内容：____________________
```

## 四、场景C：大班教学场景

### 4.1 场景描述

**发生时间**：课堂
**核心任务**：面向20-50名学生，讲解申论答题方法论
**时间预算**：90-120分钟/次
**关键要求**：互动性强、有代入感、每个学生都能参与

### 4.2 大班教学课程模块设计

基于T9教学框架，以下是**可直接使用**的6个标准化课程模块：

---

#### 模块C1：采分点意识课（90分钟）

**核心教案：**

```
【0-15min】导入：一句话值2分
  展示一道10分概括题的评分细则
  → 让学生意识到：每写一句话，要么得2分，要么得0分
  → "你的答案里，哪些话值2分，哪些话值0分？"

【15-45min】游戏：找采分点
  发下一道真题材料（A4纸打印）
  5分钟限时阅读
  3分钟写答案
  然后展示机构答案，逐句拆解（使用T8教学拆解）
  → 学生自己对比，数自己漏了几个点
  → 现场统计："漏了3个以上的请举手"

【45-70min】关键概念：硬采分点 vs 弹性采分点
  使用T6中的采分点分类表格
  让学生判断：这道题的哪些点是"非写不可"的？
  展示"上位概括=0分"案例（用T2阅卷校准数据）

【70-90min】练习+答疑
  再练一道类似的题
  现场抽2位学生的答案，投影拆解
```

**所需工具**：T6诊断模板（采分点分类部分）、T8教学拆解、T1评分细则

---

#### 模块C2：逻辑构建课（90分钟）

**核心教案：**

```
【0-15min】导入：阅卷老师15秒在找什么？
  展示阅卷顾问的"15秒定档"流程
  让学生站在阅卷者视角看3份不同结构的答案
  → "哪份你15秒就看懂了？哪份看了30秒还没找到要点？"

【15-45min】题型框架速记
  板书五大题型的逻辑框架：
  ├─ 概括题：要点1+2+3（并列）
  ├─ 分析题：是什么→为什么→怎么办
  ├─ 对策题：问题1→对策1，问题2→对策2
  ├─ 应用文：背景→问题→内容→呼吁
  └─ 大作文：开头→分论1→分论2→分论3→结尾
  
  让学生闭眼复述

【45-70min】框架应用练习
  给一道综合分析题
  学生先在草稿纸上列"是什么→为什么→怎么办"的框架
  再填空式写作
  选3位学生的框架在投影上对比

【70-90min】常见逻辑错误诊断
  使用T7失分分类中的"一锅粥""缺胳膊少腿""两张皮"
  展示错误案例→让学生诊断→修正
```

**所需工具**：T7失分分类、T9教学框架

---

#### 模块C3：规范表达课（90分钟）

**核心教案：**

```
【0-10min】导入：口语 vs 规范
  展示5组"口语→规范"对照
  "把东西做好"→"提升产品质量"
  学生自己写出3个"口语→规范"转换

【10-40min】翻译练习
  每人发一张纸，上面有10句口语化表述
  学生任务：翻译成规范表述
  集体批改，选出"最佳翻译"

【40-60min】场景化词库（使用T3政府视角评估标准）
  按6大主题（社会治理/经济发展/文化自信/生态/乡村/科技）
  每个主题讲5个核心表述+使用场景
  学生记笔记

【60-80min】"一字不多"挑战
  一段150字的答案，目标压缩到100字但不损失信息
  比谁压缩得最多且意思不变
  展示最优解

【80-90min】总结+布置任务
  每天5组"口语→规范"翻译练习
```

**所需工具**：T3政府视角（高分行话词库）、T7失分分类（模式3-1/3-2/3-3）

---

#### 模块C4：审题课（90分钟）

> 基于T7失分分类中的模式4-4"审题过急"

**核心教案：**

```
【0-15min】测试：你真读题了吗？
  发5道真题，每道题不限时但要求写下"我读到了什么"
  → 统计：平均漏读了多少要素？
  → "你以为你读了，其实你只读了一半"

【15-35min】审题清单教学
  列出审题检查清单（T7的"30秒审题法"）：
  □ 题型判断
  □ 核心任务动词（概括/分析/建议……）
  □ 特殊要求（全面/准确/有条理……）
  □ 字数限制
  □ 材料范围
  □ 身份设定
  □ 格式要求

【35-60min】设问分陷阱专项
  使用T6v1.1新增的"设问分陷阱"表格
  展示"评析但不表态""建议但不对应问题"等典型错误案例
  每个陷阱配一个正反案例

【60-80min】实战：30秒审题练习
  连续10道题，每道题给30秒读题
  时间到立刻答题卡翻面
  检查：能答出审题清单上的几个问题？

【80-90min】总结
  "读题不是'看'，是'拆解'"
  教学生：动笔前问自己3个问题
```

**所需工具**：T7失分分类（模式4-4）、T6v1.1（设问分陷阱）

#### 模块C5：大作文专项课（120分钟）

**核心教案：**

```
【0-15min】导入：一篇大作文的"生死"15秒
  展示阅卷顾问的"8秒定档"流程
  展示开头50字的"定生死"效应
  → "阅卷老师看你的开头50字，已经决定了给一类还是二类"

【15-35min】立意训练（使用T1评分细则+ T2阅卷校准）
  展示3道大作文题
  每道题给学生1分钟写出中心论点
  逐题点评：偏题了/扣题了/太浅了/有深度
  → 选3个优秀例和3个问题例，投影对比

【35-60min】论证方法（使用T8教学拆解）
  展示同一分论点的4种论证方法：
  ① 举例论证（材料案例）
  ② 因果论证（分析原因）
  ③ 对比论证（正反对比）
  ④ 引用论证（政策/名言）
  学生选择一种方法展开写一段

【60-90min】论据运用策略（使用T2第4期论据分级）
  展示阅卷顾问的论据价值分级：
  🔴 高频雷同论据（不加分）
  🟡 中频有效论据（微弱加分）
  🟢 稀缺加分论据（显著加分）
  案例：张骞凿空西域 vs 玉陵湖大桥
  → "用材料案例是及格，用独特论据才是高分"

【90-110min】整体框架练习
  给定一个题目
  15分钟内写出：
  ① 中心论点（1句话）
  ② 3个分论点（各1句话）
  ③ 每个分论点配1个论据
  抽签展示3位学生的框架

【110-120min】论据独特性的重要性
  "底线一类在双评中大概率跌回二类上"
  "头二类比底线一类更安全"
  "要拿稳一类上，需要稀缺论据"
```

**所需工具**：T2第4期（论据分级）、T8教学拆解、T1评分细则

### 4.3 课堂互动的"金句"库

根据教学经验，以下是课堂效果最好的表达方式：

```
面对学生说"我觉得我写得挺好的为什么分不高"时：
  "你觉得好是'你以为的标准'，阅卷标准才是真正的标准。
  今天我们就来对齐这两个标准。"

面对学生说"我都写了为什么要扣分"时：
  "写了是第一步，写对是第二步，写准是第三步。
  你写了但没有写准——写'设计精妙'不写'提篮拱桥'，
  阅卷老师找不到他想看的那个词。"

面对学生说"时间不够写不完"时：
  "时间不够不是终点，是你前面分配出了问题。
  我们来找：你在哪道题上多花了时间？为什么？"

面对学生说"我就是不会"时：
  "'不会'是一个结果，不是一个原因。
  我们来拆：是没读懂？是不知道格式？还是写不出来？
  这三个问题的解法完全不同。"

面对学生焦虑时：
  "你现在55分，目标是70分。
  55→60分：改掉审题和字数控制（1周）
  60→65分：提升采分点覆盖率（2周）
  65→70分：提升规范表达和论证深度（3周）
  每一步都知道怎么走，就不焦虑了。"
```

## 五、工具间的交叉验证

### 5.1 评分细则校准对照

以下是评分架构师(T1)和阅卷顾问(T2)之间的**核心差异**，教学中以阅卷顾问为准：

| 项目 | 评分架构师v1.0 | 阅卷顾问校准 | 教学使用建议 |
|------|--------------|------------|------------|
| 评分模式分类 | 3类（点/档/混合） | 2类（关键词定位/整体感知） | 采用2类，更接近真实 |
| 部分匹配赋分 | 50-70% | **0%**（上位概括=不匹配） | **用阅卷顾问的标准** |
| 概括题条理性分 | 2分（得分项） | 1分（扣分项） | 作为扣分项而非加分项 |
| 大作文一类上 | 33-35分 | 30-32分实达 | 目标设30-32分，35为理论 |
| 综合分析结构要求 | 强制三段式 | 灵活，看观点+深度 | 教三段式但不要机械扣分 |
| 应用文格式 | 统一标准 | 因文体而异 | 按文体分别教格式 |
| 抄材料扣分 | 降一档 | 区分"引用"和"复制" | 教学生"引用"而非"复制" |

### 5.2 机构答案评分对照

批改时参考机构精析师(T4)的评分，可快速判断学生答案的相对水平：

```
学生得分 → 与机构答案对比：
  如果学生得分接近/超过某笔 → 优秀水平
  如果学生得分接近/超过中公 → 中上水平
  如果学生得分明显低于各机构 → 需要系统性提升

注意：
  - 机构答案是"精心准备的完美答案"
  - 学生在考场限时下答到机构答案的70-80%就是优秀了
  - 不要以机构答案为满分标准
```

### 5.3 政府视角校准对照

对于关注政府思维的题型，使用政府实务顾问(T3)的标准进行额外校准：

```
批改一道对策题/应用文时，先完成标准评分，再额外问：
□ 答案中的对策是否有执行主体？
□ 对策是否具体可操作（有抓手）？
□ 身份口吻是否符合题目设定？
□ 公文用语是否规范？（江苏A卷尤其注意）
□ 是否体现了政治素养而非空喊口号？
```

## 六、常见问题FAQ

### Q1：诊断的频次应该是怎样的？

```
理想频次：
  - 每次课后作业 → 批改+简短反馈（15分钟/份）
  - 每2周一次深度诊断 → 使用完整T6模板
  - 每4周一次全面复盘 → 对比进步曲线

最低频次（时间不够时）：
  - 每周至少1次深度诊断
  - 每次诊断至少解决1个问题
  - 每问题至少跟踪2周
```

### Q2：遇到"每个问题都有一点"的学生怎么办？

```
策略：先聚焦最致命的1个问题
  - 如果都有一点 → 说明没有系统训练
  - 优先级判断：
    ① 审题是否有问题？（是→先解决审题）
    ② 阅读是否有问题？（采分点覆盖率<60%→先解决阅读）
    ③ 逻辑是否有问题？（答案一团乱→先解决结构）
    ④ 表达是否有问题？（以上都没问题再解决表达）
  - 每次只改1个，改好再进入下一个
```

### Q3：学生说"我背了很多模板，为什么还是低分"？

```
诊断：
  - 模板不是问题，问题是"只会套模板、不会灵活调整"
  - 阅卷顾问说：模板被识破会直接给低分

解决方案：
  - 去模板化（参见T7模式4-3"模板病"）
  - 教学生：模板是"脚手架"，不是"建筑本身"
  - 展示"模板答案"和"非模板答案"的得分差异
  - 练习时禁用所有模板句
```

### Q4：时间不够，批改不过来怎么办？

```
优先级策略：
  ① 先批改"有明显问题"的作业（问题少的作业快速过）
  ② 每次只写"1个P0+2条改进建议"，不写长篇大论
  ③ 使用T10闭环中的"快速诊断"模式（15分钟/份）
  ④ 善用学生自评：让学生先自评，你再核验

高效批改模板（3分钟版）：
  得分：___/___  档位：___
  P0问题：____________________
  具体建议：__________________
  练习任务：__________________
```

### Q5：学生和家长想看到"进步证据"，怎么呈现？

```
使用T10的进步曲线追踪：
  ① 每次诊断记录各维度得分（阅读理解/逻辑/表达/策略）
  ② 每月画一张折线图
  ③ 标注里程碑（如"某月某日，概括题首次突破85%"）
  ④ 给家长看的简报模板：
    "本月进步：总分从__分提升到__分
     最显著变化：______（具体说明）
     下月重点：______"
```
