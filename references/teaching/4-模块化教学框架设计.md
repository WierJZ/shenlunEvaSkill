## 二、分模块详细设计

### M1：阅读理解基础模块

> 所有题型的"地基"。本模块不训练答题技巧，只训练"从材料中提取信息"的能力。

**适用对象**：进阶学生（入门者必学，已有基础者可选修复补）

#### 核心知识点

| 知识点 | 内容说明 | 训练方式 |
|-------|---------|---------|
| 关键词定位法 | 动词、名词、关联词、"做法类"标志词 | 逐段练习 |
| 段落结构分析 | 总-分/分-总/并列/递进/转折 | 段落结构图 |
| 材料速读技巧 | 首尾句法、跳读法、标注法 | 限时阅读训练 |
| 信息筛选标准 | 区分"要点"和"背景""例子""数据" | 信息分类练习 |
| 多材料关联阅读 | 同一主题多则材料的逻辑关系 | 关联图绘制 |

#### 训练方案

```
【训练一：逐段圈词】（每天1篇，连续7天）
  步骤：
  1. 读一段，用笔圈出该段中所有"动词+名词"组合
  2. 在旁边标注：①这是核心要点 ②这是次要信息 ③这是背景
  3. 整篇读完后，整理出"核心要点清单"
  4. 对照机构答案的采分点清单，看自己漏了哪些
  5. 分析漏掉的原因（没看到？没读懂？忽略了？）

【训练二：段落结构图】（每天1篇，连续5天）
  步骤：
  1. 读完全文后，画出"段落关系图"
  2. 标注：总起段/分述段/转折段/总结段
  3. 标出核心段落和非核心段落
  4. 训练"哪段详细读、哪段快速读"的判断力

【训练三：限时精读】（隔天1次，连续5次）
  步骤：
  1. 限定15分钟读完1篇材料（约1000-1500字）
  2. 读完合上材料，默写"材料核心信息"（不限字数）
  3. 打开材料核对，看你记得的内容和没记住的内容
  4. 反复练习"在压力下抓取关键信息"
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 精读1篇材料时间 | ≤20分钟 | ≤15分钟 |
| 要点覆盖率 | ≥80% | ≥90% |
| 段落结构判断准确率 | ≥80% | ≥90% |

### M2：概括归纳专项模块

> 概括能力是申论的"数学基本功"——所有题型的答题基础。本题型在国考和江苏考中占比约20-25%。

#### 核心知识点

| 知识点 | 内容说明 | 考试分值占比 |
|-------|---------|:----------:|
| 概括的"度" | 到什么程度叫"概括"、到什么程度叫"复述" | 15% |
| 动宾短语提取 | "动词+核心名词"的概括公式 | 25% |
| 信息分类合并 | 同类信息合并、不同类信息分开 | 15% |
| 逻辑排序 | 按材料顺序/按重要程度/按逻辑关系排序 | 10% |
| 字数控制 | 每个要点写多少字才合理 | 10% |
| 题型变体识别 | 常规概括/限定条件概括/分角度概括 | 25% |

#### 训练方案

```
【训练一：5分钟-250字挑战】（每天1道，连续10天）
  任务：10分概括题，限时10分钟，写完250字
  要求：
  - 必须分5个要点（即使不确定，也要列出5条）
  - 每个要点不超过50字
  - 使用"动宾短语"结构
  自检：对照机构答案，数自己覆盖了几个采分点

【训练二：信息压缩比赛】（每2天1次，连续5次）
  任务：同一段材料（200-300字），用20/40/60字概括
  目的：训练"用最少字说清核心信息"的能力
  技巧：去掉状语、去掉定语、只留主谓宾

【训练三：一题多练法】（每周1题，连续4周）
  任务：同一道概括题做3次
  第1次：正常做（不限时，追求完整）
  第2次：限时做（10分钟，追求速度）
  第3次：限字做（字数缩到要求的80%，追求精炼）
  对比3次答案，找出"最稳定的核心要点"
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 10分概括题得分 | ≥8分 | ≥9分 |
| 15分概括题得分 | ≥12分 | ≥14分 |
| 每题用时 | ≤12分钟 | ≤10分钟 |
| 字数偏差 | ≤10% | ≤5% |

### M3：综合分析专项模块

> 综合分析是"拉开分差"的关键题型。国考副省级卷尤其重视综合分析能力。本题型在考试中占比约20-25%。

#### 核心知识点

| 知识点 | 内容说明 | 考试分值占比 |
|-------|---------|:----------:|
| "是什么-为什么-怎么办"框架 | 综合分析的"铁三角"逻辑 | 30% |
| 观点提取与判断 | 从材料中提炼核心观点并明确表态 | 20% |
| 多维度分析 | 原因分析/影响分析/对比分析/可行性分析 | 25% |
| 论证方法 | 举例论证/引用论证/因果论证/对比论证 | 15% |
| 题型变体 | 词句理解/观点评价/现象分析/对比分析 | 10% |

#### 训练方案

```
【训练一：框架填空法】（每天1道，连续10天）
  每次答题前，先在草稿纸上写：
  一、是什么（观点/含义）：___________
  二、为什么（原因/影响）：___________
  三、怎么办（对策/启示）：___________
  填空完成后，再写完整答案

【训练二：一句话观点练习】（每天3题，连续7天）
  任务：只看题目不读材料，用一句话说出"你认为这道题的核心观点是什么"
  目的：训练"快速抓取分析题核心"的能力
  标准：一句话说清，不超过30字

【训练三：分析深度提升】（每周2题，连续4周）
  针对同一道分析题，要求自己写出3层分析：
  第1层：直接原因（材料中明写的）
  第2层：间接原因（需要从材料中推导的）
  第3层：深层原因（需要结合背景知识理解的）
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 观点明确度 | 首句即亮观点 | 观点+核心判断 |
| 逻辑完整性 | 完整覆盖"是什么-为什么-怎么办" | 三个环节递进清晰 |
| 论证充分度 | 至少2个论据支撑 | 论据+分析 |
| 得分率 | ≥75% | ≥85% |

### M4：提出对策专项模块

> 对策题在江苏卷中出现频率高于国考。本题型占比约15-20%。

#### 核心知识点

| 知识点 | 内容说明 | 考试分值占比 |
|-------|---------|:----------:|
| "问题-对策"对应 | 每条对策必须针对一个具体问题 | 25% |
| 对策可行性检验 | 主体+手段+目标三位一体 | 25% |
| 对策来源 | 材料直接给/材料推导/知识补充 | 20% |
| 常见对策领域 | 制度/监管/技术/人才/资金/宣传 | 15% |
| 对策排序 | 紧急优先/治本优先/易行优先 | 15% |

#### 训练方案

```
【训练一：问题-对策对照表】（每天1道，连续7天）
  步骤：
  1. 先列出材料中的所有问题清单
  2. 在每个问题后面写"对策"
  3. 检查：每条对策是否有主体
  4. 检查：每条对策是否可操作
  格式：
  问题1：___________ → 对策1：___________（主体：___ 手段：___ 目标：___）

【训练二：可行性审核练习】（每2天1次，连续5次）
  写完后对自己"三问"：
  Q1：这个对策"谁来做"写清楚了吗？
  Q2：这个对策"具体怎么做"写清楚了吗？
  Q3：这个对策做了之后"能达到什么效果"写清楚了吗？
  三个都写清楚了，才是可行对策

【训练三：对策精细化训练】（每周2题，连续3周）
  同一问题，写出3个不同层次的对策：
  层次1：应急措施（马上能做的）
  层次2：制度措施（需要一段时间推行的）
  层次3：根本措施（长期才能见效的）
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 问题-对策对应率 | ≥90% | 100% |
| 对策可行性 | 有主体有手段 | 主体+手段+目标完整 |
| 对策具体度 | 3句以上具体内容 | 信息密度高 |
| 得分率 | ≥75% | ≥85% |

### M5：应用文写作专项模块

> 应用文在近三年国考和江苏考中频率显著上升，需重点准备。本题型占比约15-20%。

#### 核心知识点

| 知识点 | 内容说明 | 考试分值占比 |
|-------|---------|:----------:|
| 9种常考文体格式 | 倡议书/讲话稿/调研报告/简报/建议/工作方案/宣传稿/公开信/汇报材料 | 20% |
| 身份-口吻匹配 | 不同身份使用不同的语气和视角 | 15% |
| 内容要素完整性 | 每类文体必须覆盖的要素清单 | 25% |
| 应用文逻辑结构 | 背景-问题/意义-内容-呼吁 | 20% |
| 格式-内容权重分配 | 不同题型的格式分和内容分比例不同 | 10% |
| 材料转化技巧 | 把材料语言转化为应用文所需语言 | 10% |

#### 训练方案

```
【训练一：文体-格式速查表建立】（一次性任务）
  整理"9种文体格式对照表"，每种文体包含：
  - 格式要素（标题/称谓/落款/日期等）
  - 必备内容模块（如调研报告必须包含"现状-问题-建议"）
  - 常见错误
  - 1个优质范本

【训练二：身份转换练习】（每天1题，连续7天）
  同一段材料内容，用3种不同身份写：
  版本1：以"市政府工作人员"身份写工作建议
  版本2：以"社区工作者"身份写倡议书
  版本3：以"调研组成员"身份写汇报
  目的：训练"同一内容、不同口吻"的能力

【训练三：格式速查+要点填充】（每次练习前必做）
  步骤：
  1. 看到题目，立刻判断"这是什么文体"
  2. 默写/看表确认该文体的格式要素
  3. 按各要素填充内容
  4. 写完后逐项检查格式
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 文体识别准确率 | 100% | 100% |
| 格式完整度 | 必备要素齐全 | 要素+细节准确 |
| 身份口吻匹配 | 基本符合身份 | 口吻自然贴切 |
| 得分率 | ≥75% | ≥85% |

### M6：大作文专项模块

> 大作文占总分30-35%，是"得作文者得申论"的关键。本题型对综合能力要求最高。

#### 核心知识点

| 知识点 | 内容说明 | 考试分值占比 |
|-------|---------|:----------:|
| 立意与审题 | 中心论点提炼、角度选择、深度把控 | 20% |
| 结构框架 | 总分总/并列式/递进式/辩证式 | 15% |
| 论证方法 | 因果/对比/举例/引用/类比论证 | 20% |
| 素材积累与运用 | 5大主题素材库建立、素材-论点匹配 | 15% |
| 语言风格 | 申论语言规范度、句式变化、修辞运用 | 15% |
| 开头与结尾 | 开头引人入胜、结尾升华主题 | 15% |

#### 训练方案

```
【训练一：立意训练】（每天1题，连续10天）
  只练审题和立意，不写全文：
  1. 读题目（读3遍）
  2. 写出中心论点（1句话，20字以内）
  3. 写出3个分论点（每句15字以内）
  4. 找老师/同学看，确认"不偏题"
  5. 通过后，继续下一题

【训练二：论证段落强化】（每天1段，连续14天）
  只练主体段落的论证，不写开头不写结尾：
  1. 给定一个分论点
  2. 写出不少于200字的论证段落
  3. 要求包含：论点句→阐释句→论据句→分析句→小结句
  4. 自检：是否形成完整的论证闭环

【训练三：素材-论点匹配练习】（每周2次，持续全程）
  1. 写出一个论点
  2. 列出3个能支撑该论点的素材
  3. 为每个素材写"素材→论点"的连接句
  4. 目的是让素材和论点"咬合"
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|------|:-----:|:-----:|
| 立意是否偏题 | 不偏题 | 有深度有角度 |
| 结构清晰度 | 总分总结构完整 | 结构有层次递进 |
| 论证有效性 | 有论点有论据 | 论证充分有分析 |
| 字数 | 1000-1200字 | 1050-1150字 |
| 档位 | 二类文（20-24分） | 一类文（25-30分） |

### M7：套题实战训练模块

> 从"会做单题"到"会做一套题"的跨越。

#### 核心知识点

| 知识点 | 内容说明 |
|-------|---------|
| 时间分配策略 | 按分值分配时间、各题的"黄金时间区间" |
| 做题顺序选择 | 先做熟的/先做分值高的/按题目顺序 |
| 答题卡的利用 | 草稿分区、提纲位置、时间记录 |
| 临场应变 | 遇到生题怎么办、遇到不会的怎么办 |
| 检查策略 | 什么需要检查、什么不需要检查 |

#### 训练方案

```
【套题模拟流程】
  第1步：全真模拟（150分钟，严格计时）
  第2步：自我评分（对照机构答案，算分）
  第3步：错题分析（哪道题失分最多？为什么？）
  第4步：针对性补强（针对薄弱点安排专项训练）
  第5步：隔周再来一轮（同样的流程，对比进步）

注意：
- 前2套重点在"适应节奏"，不追求分数
- 第3-5套重点在"时间分配"，找到适合自己的节奏
- 第6-8套重点在"全面发力"，追求稳定发挥
```

#### 达标标准

| 指标 | 达标线 | 优秀线 |
|:----:|:-----:|:-----:|
| 整套完成率 | 100% | 100% |
| 时间偏差 | ≤15分钟 | ≤10分钟 |
| 单题最低分 | 不低于该题分的50% | 不低于60% |
| 总分（按100分折算） | ≥60分 | ≥75分 |

## 三、教学进度建议

### 方案A：长线备考（6个月以上）

```
第1-2月：M1阅读理解+M2概括归纳（夯实基础）
  每周：4天专项训练+1天复盘+2天休息

第3-4月：M3综合分析+M4提出对策（提升能力）
  每周：3天专项+1天套题+1天复盘+2天休息

第5月：M5应用文+M6大作文（重点突破）
  每周：3天专项+2天套题+2天休息

第6月：M7套题实战+M8冲刺（考前冲刺）
  每周：3天套题+1天补弱+1天复盘+2天休息
```

### 方案B：中短期备考（2-3个月）

```
第1月：M1+M2核心基础（快速扫过）+ M3+M4题型突破
  每周：2天基础+2天题型+1天套题+2天休息

第2月：M5+M6重点突破+套题实战
  每周：2天作文类+3天套题+2天复盘

第3月：M7套题强化+M8冲刺
  每周：4天套题+2天补弱+1天复盘
```

### 方案C：极速备考（1个月以内）

```
时间分配策略：
  第1周：每天1套真题，快速摸底
  第2周：重点攻克"日均提分最快"的题型（应用文格式+大作文结构）
  第3周：套题实战+时间分配训练
  第4周：错题回顾+考前冲刺

优先级：
  应急策略 ≈ 应试技巧 > 大作文结构 > 概括归纳 > 综合分析 > 对策题
```

### 作业布置原则

1. **少而精**：每天1道精练题 + 1道快速练习，不要贪多
2. **题后必复盘**：每题做完必须有"复盘"环节，复盘时间不少于做题时间的1/3
3. **隔周重做**：做过的错题隔周重做一次，确认是否真正掌握
4. **量变到质变**：每个模块训练量达到标准后再进入下一模块
