## 二、各环节详细设计

### 环节①：学生提交答案

#### 提交方式

| 提交方式 | 适用场景 | 操作说明 |
|---------|---------|---------|
| 文字提交 | 在线学习 | 学生直接输入/粘贴答案到学习系统 |
| 拍照提交 | 纸质练习 | 学生将写在申论纸上的答案拍照上传 |
| 语音转文字 | 练习场景 | 学生口述答案思路，转为文字稿 |

#### 学生提交时需要提供的信息

```
□ 题目（完整题目原文，或标注"2025国考行政执法卷·第1题"）
□ 我的答案（完整答案）
□ 限时情况（是否完全限时完成）
□ 自我预估（你觉得这道题大概能得多少分）
□ 主要困惑（你感觉最拿不准的问题是什么）
```

#### 提交时效要求

| 类型 | 提交时限 | 备注 |
|:----:|:--------:|------|
| 随堂练习 | 课堂结束前 | 当堂反馈 |
| 课后作业 | 下次课前24小时 | 确保老师有分析时间 |
| 套题模拟 | 模拟结束后2小时内 | 趁记忆清晰 |

### 环节②：生成诊断报告

#### 诊断流程

```
Step 1：材料对照（5分钟）
  - 对照题目材料，确认学生答案的信息来源
  - 标注"哪些要点有出处、哪些没有"
  - 识别误解和漏读的位置

Step 2：采分点比对（10分钟）
  - 用《诊断模板》中的采分点清单逐条核对
  - 标注：命中 ✓ / 遗漏 ✗ / 偏差 △
  - 给每个采分点评分（满分多少，得多少）

Step 3：分维度评估（5分钟）
  - 阅读理解：信息提取是否全面准确
  - 逻辑构建：结构是否合理清晰
  - 规范表达：语言是否规范简洁
  - 应试策略：时间/字数/格式/审题

Step 4：优先级排序（3分钟）
  - 从所有问题中选出"最致命的一个"作为P0
  - 选出2-3个重要问题作为P1
  - 其余标注为P2

Step 5：填写诊断报告（10-15分钟）
  - 按照《诊断模板》填写
  - 注意：每条失分点都要有"怎么改"
  - 注意：语言要"学生能听懂"
```

#### 诊断时间线

```
学生提交答案
    ↓（24小时内）
诊断报告交付学生
    ↓（诊断报告交付后24小时内）
第③步：诊断反馈会
```

#### AI辅助诊断（可选）

可借助AI进行初步的"快速诊断"，但最终诊断报告必须由人工审核校准：

```
AI快速诊断：
  - 自动比对机构答案采分点
  - 标注遗漏要点
  - 统计字数/字数偏差
  - 检测明显格式错误

人工校准（必须）：
  - 确认AI标记的遗漏是否确实遗漏
  - 评估"遗漏"是偶然失误还是能力问题
  - 判断答案的"真实性"——是否真正理解了材料
  - 给出深度原因分析
```

### 环节③：诊断反馈会

#### 反馈会流程（15分钟）

```
0-2分钟：总体定性
  "这次你的得分是____/____，比上次进步了/退步了____分。
  最大的变化是______。"

2-8分钟：逐点过问题
  按优先级逐个讲解：
  "问题①：你的第_段中，________（展示学生原文）。
  标准答案应该是________。
  为什么扣分？因为________。
  我们这样改：________。"

8-12分钟：学生提问+确认
  - 问学生："这部分听明白了吗？"
  - 让学生复述：""那我接下来该怎么做？"
  - 确认学生确实理解了自己的问题

12-15分钟：布置改进任务
  "接下来3天，你的任务是：每天做1道____题，
  重点练习________。做完发我检查。"
```

#### 反馈沟通技巧

| 应避免的说法 | 应使用的说法 |
|------------|------------|
| "你这段写得不对" | "这段写的时候，你可能是想表达____，但材料说的其实是____" |
| "你又漏了要点" | "我注意到你这次漏了材料第_段中关于____的信息，我们来看看怎么发现的" |
| "这个太差了" | "这个点我们还有提升空间，现在得分_X_分，通过练习可以提到_X_分" |
| "要好好练习" | "接下来3天我们做3件事：____、____、____" |
| "这是基本功问题" | "这部分基础不够扎实，我们从最基础的练习开始补" |

#### 反馈会形式选择

| 形式 | 适用场景 | 优点 | 缺点 |
|-----|---------|------|------|
| 一对一当面 | 线下教学/重点学生 | 沟通彻底 | 耗时长 |
| 语音/视频 | 线上教学 | 灵活方便 | 无法实时演示 |
| 文字版诊断报告 | 作业反馈 | 可反复查看 | 缺少互动 |

**建议**：每次诊断至少安排一次"实时反馈"（当面或语音），文字报告作为补充资料。

### 环节④：制定改进计划

#### 改进计划要素

```
╔═══════════════════════════════════════════════════╗
║  学生改进计划                                    ║
╠═══════════════════════════════════════════════════╣
║                                                   ║
║  🔴 P0问题（本周必须解决）：                      ║
║    问题：___________________                     ║
║    训练方案：___________________                 ║
║    预计投入：每天_X_分钟，共_X_天                 ║
║                                                   ║
║  🟡 P1问题（两周内解决）：                        ║
║    问题：___________________                     ║
║    训练方案：___________________                 ║
║    预计投入：每天_X_分钟，共_X_天                 ║
║                                                   ║
║  🟢 P2问题（有余力时解决）：                      ║
║    问题：___________________                     ║
║    训练方案：___________________                 ║
║                                                   ║
║  📅 下周六复查项目：___________________          ║
║                                                   ║
║  ✍️ 学生签字确认：______  日期：______           ║
║                                                   ║
╚═══════════════════════════════════════════════════╝
```

#### 制定改进计划的原则

1. **每次只解决1个P0问题**——不要试图同时改所有问题
2. **训练方案要具体到"做什么、做多少、怎么做"**
3. **可量化**——"每天读3篇材料"比"多读材料"有效100倍
4. **有检查机制**——学生做完练习后能自检是否达标
5. **合乎学生时间**——不能要求上班族每天练4小时，不现实

#### 改进计划示例

```
学生：张同学
问题：概括题"漏读症"——采分点只覆盖50%

改进计划：
🔴 P0：提升采分点覆盖率（当前50%→目标85%以上）
  - 训练方案：「逐段圈词法」
  - 每天：精读1篇材料（15分钟）+ 填写要点提取表（10分钟）
  - 共：连续7天
  - 自检：圈出的要点能否覆盖机构答案采分点的85%以上

🟡 P1：提升概括精炼度
  - 训练方案：「字数压缩法」
  - 从P0训练的第4天开始，加入"50字概括一段"练习
  - 每天：3段压缩练习（10分钟）

🟢 P2：无（先解决P0）
```

### 环节⑥：复诊确认

#### 复诊机制设计

```
【初诊】→ 诊断报告 + 改进计划
   ↓（经过_X_天的训练）
【复诊】→ 同一题型，同类题目，重新完成
   ↓
对比初诊和复诊的诊断报告：
  - 是否解决了P0问题？
  - 之前遗漏的采分点现在是否全了？
  - 有没有出现新的问题？

根据复诊结果判断：
  ✅ 问题已解决 → 宣布该问题"结项"，进入下一个问题
  ⚠️ 部分改善 → 回到改进计划，调整训练方式
  ❌ 没有改善 → 重新诊断，可能是"表层下另有深层原因"
```

#### 复诊频率

```
第1次复诊：改进训练开始后第7天（解决P0后的确认）
第2次复诊：改进训练开始后第14天（P0巩固 + P1进展）
第3次复诊：改进训练开始后第28天（整体进步评估）
定期复诊：之后每月1次（防止问题反复）
```

### 进步曲线分析规则

```
正常进步期望值：
  - 每周提升：2-3分（前4周）
  - 每月提升：8-10分（前2个月）
  - 后期增长减缓：从70分提升到75分可能比从50分提升到60分更难

预警信号：
  ⚠️ 连续2次诊断分数下降 → 检查是否训练量过大导致疲惫/错误方法
  ⚠️ 连续3次诊断分数不变 → 检查是否遇到了瓶颈，需要调整训练方式
  ⚠️ 某题型得分率突然下降30%以上 → 检查是否出现了新的问题或理解偏差

正向信号：
  ✅ 得分稳步上升 → 训练方法是有效的，继续保持
  ✅ 某题型"突破"——从60%到80% → 说明该维度的训练奏效了
  ✅ 大作文从三类到二类 → 这是质的飞跃，值得庆祝
```

## 四、完整案例演示

### 案例：张同学的学习闭环

#### 第1周：初诊

```
提交答案：2025国考行政执法卷·第1题（概括题）
诊断结果：得分5/10分
核心问题：采分点遗漏（只覆盖了3/5的点）
P0问题：漏了"资金支持"和"人才培养"两个采分点

改进计划：
  🔴 P0：逐段圈词法，每天1篇，连续7天
  
反馈：
  张同学在反馈会上说："我以为我抓得挺全的，没想到漏了这么多……"
  我："我们从材料里慢慢看：你漏掉的'资金支持'在第_段、
  '人才培养'在第_段，你读这两段的时候在想什么？"
  张同学："这两段我扫了一眼，觉得'不是重点'就跳过了……"
  我："问题找到了——你在替材料做判断，而不是让材料告诉你什么重要。
  接下来的练习，你的任务是：不准跳段，每段必须至少圈1个要点。"
```

#### 第2周：复诊（第1次）

```
训练执行情况：7天全部完成，每天1篇精读
训练中数据：第1天覆盖率45% → 第3天65% → 第7天80%

复诊题目：2025国考行政执法卷·第2题（分析题，非概括题）
诊断结果：得分10/15分
进步分析：
  - 阅读理解维度：从4/10 → 7/10（↑）
  - 采分点覆盖率：从55% → 75%（↑）
  - 问题：分析题的逻辑框架还不够熟练

新一轮改进计划：
  🔴 P0：继续保持阅读习惯，巩固成果
  🟡 P1（新）：分析题的"是什么→为什么→怎么办"框架训练
```

#### 第4周：复诊（第2次）

```

  - 采分点覆盖率：80%（稳定）

结论：P0问题已基本解决，开始进入P1问题的深入训练
```

#### 第8周：复诊（第3次）

## 五、闭环运营管理

### 角色与职责

| 角色 | 职责 | 关键产出 | 对接人 |
|-----|------|---------|-------|
| 教学转化师 | 主诊、出报告、反馈会 | 诊断报告+改进计划 | 学生、团队 |
| 班主任/助教 | 跟踪作业、督促练习、记录数据 | 作业完成记录+进步曲线 | 学生 |
| 学生本人 | 执行训练、提交作业、复盘反思 | 练习成果+复盘记录 | 老师/助教 |
| 家长（如适用） | 提供支持、了解进度 | 无 | 班主任 |

### 时间线管理

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│  周次    │  周一    │  周三    │  周五    │  周末    │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│  诊断周  │ 提交答案 │ 诊断报告 │ 反馈会   │ 制定计划 │
│  训练周1 │ 练习+提交│ 反馈+练习│ 练习+提交│ 反馈+复盘│
│  训练周2 │ 练习+提交│ 复诊(1)  │ 反馈会   │ 调整计划 │
│  训练周3 │ 练习+提交│ 练习+提交│ 复诊(2)  │ 反馈会   │
│  训练周4 │ 练习+提交│ 练习+提交│ 练习+提交│ 月度复盘 │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 质量管理规则

1. **诊断报告时效**：学生提交后24小时内必须交付（最迟不超过48小时）
2. **反馈会时效**：诊断报告交付后24小时内进行
3. **作业反馈时效**：学生提交作业后24小时内反馈
4. **复诊频率**：每解决1个P0问题后安排1次复诊
5. **月度总结**：每月1次全面的进步评估和教学计划调整

### 常见问题应对

| 问题 | 应对方式 |
|------|---------|
| 学生不按时提交作业 | ① 了解原因（太忙/太难/忘记了）② 调整任务量 ③ 设定固定提交时间 |
| 学生训练后没有进步 | ① 重新诊断是否"找对了原因" ② 换训练方法 ③ 检查训练量是否足够 |
| 学生理解不了诊断反馈 | ① 换更通俗的语言 ② 用例子代替理论 ③ 让学生用自己的话复述一遍 |
| 学生陷入"提分瓶颈" | ① 检查当前训练方法是否需要升级 ② 考虑是否是知识积累到了需要"质变"的关口 ③ 适当降低目标，分解为更小的阶段性目标 |
| 学生出现"反弹"（之前解决的问题重新出现） | ① 这是正常现象，不代表训练失效 ② 确认是"偶尔失误"还是"惯性回归" ③ 如果是惯性回归，增加间隔重复练习 |
| 考前学生焦虑 | ① 引导关注"我的进步"而非"还有多少没学" ② 降低练习难度，增加信心 ③ 教授应对焦虑的呼吸/心理调节技巧 |
