### 1.4 教学转化师的拆解需要补充的要点

**当前教学拆解（文件#3）的不足**：

1. **只有国考数据** → 学生可能会以为"国考的标准答案就是全国通用的"，实际上江苏答题策略不同
2. **缺少"分类能力"的教学** → 国考Q1直接提取关键词即可，但江苏Q1需要将5个案例归类。这是两种不同的能力
3. **缺少"政治素养嵌入差异"的教学** → 江苏A卷综合分析题需要"观点先行"，国考概括题不需要

**建议补充的教学内容**：

```
补充1：「国考vs江苏，答题策略差异」

国考策略（以2025国考行政执法Q1为例）：
  直接提取原文关键词 → "成立专班""搭建平台""建设园区"
  不需要分类 → 材料本身就是按"做法"分的

江苏策略（以2025江苏A卷Q1为例）：
  需要"归类整合" → 5个案例不能简单罗列
  需要"成效导向" → 概括的是"成效"而非"做法"
  可能嵌入政治素养 → 江苏A卷综合分析题需要"观点先行"

教学要点：告诉学生"备考哪个省、用哪个策略"
```

```
补充2：「同一个机构，不同省份的表现可能不同」

例1：唐棣
  江苏A卷Q1：⭐⭐⭐⭐⭐ 归类最佳
  国考：无数据，但按他的风格推测 → 可能因"加戏"被扣分

例2：Kiwi  
  国考行政执法Q1：⭐⭐⭐⭐ 8分（内容完整但归类不够）
  江苏A卷Q1：⭐⭐⭐⭐ 17分（内容好但结构略散）
```

```
补充3：「江苏偏好的答案特征（vs国考）」

江苏更看重：
  ① 归类是否合理（五个案例不是随便排的）
  ② 是否有一定的文采（"触摸历史心跳"比"消费者获得更好体验"得分高）
  ③ 综合分析题是否"观点先行"

江苏不太看重：
  ① 是不是"抄原文关键词"（江苏允许一定程度的概括）
  ② 政治表态的密度（不是越多越好，要在关键处自然展示）
```

### 1.5 给教学转化师的"三看"原则补充

教学转化师在#3文件末尾的"三看"原则（点/序/度）很好。建议补充**第四个"看"**：

```
四看"省"（省份适应性）
- 同一答案在国考可能满分，在江苏可能只有80%
- 教学时要问学生：你在准备哪个省的考试？答案策略要跟着调整
- 具体判断方向：
  ├─ 国考 → 原文关键词优先，压缩文采空间
  ├─ 江苏A卷 → 归类+观点+适当文采
  ├─ 江苏B/C卷 → 更接近国考行政执法（务实型）
  └─ 联考 → 各省差异大，需具体分析
```

## 第三部分：学生版机构参考指南

### 🎯 备考国考行政执法——优先参考机构

#### 【第一推荐：粉笔】
**理由**：国考全题型标杆，答案结构最规范、采分点最全、字数控制最准。

**适用阶段**：基础学习→考前冲刺，全程可用。

**参考方法**：
```
练习时 → 先自己写，再对照粉笔答案检查漏了哪些点
复习时 → 用粉笔答案当"参考答案"背诵核心关键词
考前 → 重点看粉笔的"字数控制"——每条多少字、总字数多少
```

**⚠️注意**：粉笔Q5大作文偶尔偏模板化。如果目标是30+，建议同时参考半月谈白鹭/福州青云端的大作文。

#### 【第二推荐：千寻申论】
**理由**：采点扎实、语言简洁、字数控制好（2025执法Q1精准250字）。在国考行政执法类中表现稳定。

**适用阶段**：基础阶段，作为粉笔答案的"参照系"——两家都写的=铁板采分点。

**参考方法**：
```
同时看粉笔+千寻对同一题的答案 → 
  两家都写的 = 铁板采分点（必须写）
  粉笔写了千寻没写的 = 加分项（可写可不写）
  千寻写了粉笔没写的 = 独有判断（可能是黑马，也可能是冗余）
```

#### 【备选：袁东/纵横公考】
**理由**：
- **袁东**：Q1-Q4客观题覆盖全、质量高，风格务实
- **纵横公考邓淳**：Q1-Q4小而精，所有题型都有参与

### 🎯 备考江苏A卷——优先参考机构

#### 【第一推荐：唐棣】
**理由**：2025江苏A卷Q1的7家答案中，唐棣的**归类能力**最强（将5个案例分为文化传承/品牌创新/城市宣传/产业发展），这恰好是江苏阅卷最看重的"归类合理"能力。而且他的答案有具体的**江苏省情要素**（常州"秋白书苑"、南京"艺栖夜课"等）。

**适用阶段**：学习"如何给案例分类"时必看。

**参考方法**：
```
重点学习唐棣的"分类方法"：
  他不是简单罗列5个案例如"南京/西安/山西/自贡/苏州"
  而是按维度分类："文化传承上/品牌创新上/城市宣传上/产业发展上"
  → 这是江苏阅卷最喜欢的"归类合理"
```

#### 【第二推荐：华图】
**理由**：华图在2024江苏A卷Q2（阅读推广vs阅读推销）上被阅卷顾问评了90分——**全场最高**。他的核心优势是"观点分"处理得好（"阅读推广是公益行为，阅读推销是一种营销形式"），这正是江苏和国考的最大区别——江苏要求"观点先行"。

**适用阶段**：练习综合分析题时看。

**参考方法**：
```
华图的"立场先行"结构：
  第一步：直接表明立场（"阅读推广是公益行为，值得肯定；阅读推销是营销形式，需要规范"）
  第二步：分列事实依据  
  第三步：提出对策建议
  → 江苏综合分析题的"标准答题公式"
```

#### 【备选：粉笔（客观题）/ Kiwi（内容完整性）】
**理由**：
- **粉笔**：在江苏A卷Q1客观题中依然是质量最高的之一，但要注意江苏要求"一段话"而非分条
- **Kiwi**：内容完整性好，但归类清晰度不如唐棣

### 🎯 大作文专项——避坑指南

#### 【强烈推荐的机构：半月谈白鹭、站长、福州青云端徐阳】

**半月谈白鹭**（"流动与新生"一类中29-31分）：
```
开篇："张骞凿空西域到一带一路"——格局大
结构：打基础→谋发展→促循环——递进式
亮点：会用比喻（"气沉丹田""任督二脉"）
⚠️注意：比喻不要过于随意，可能被部分阅卷者认为不够正式
```

**站长**（一类中29-31分）：
```
结构：二分法（打基础+破束缚）——简洁有力
语言：既有高度又有温度——平衡感最好
优点：排比句开头有气势，引用习近平讲话自然
```

**福州青云端徐阳**（2025执法Q5大作文32分估）：
```
特色：引用密度极高（习近平总书记、古诗词、排比多层次）
语言：文采斐然但不过度
结构：三维递进（主动担当→流程优化→长效机制）
适用：文采基础好的学生冲刺一类上
```

#### 【避坑机构：这3类大作文答案不要学】

**第1类：模板三板斧** ❌
```
特征：
  开头"随着我国经济的快速发展……"
  分论点"加强立法+完善制度+加大宣传"
  结尾"让我们共同努力……"
  
代表：部分机构的"万能模板"答案
避坑原因：阅卷者一眼看穿是模板 → 直接二类起评
```

**第2类：纯理论派（哲学腔）** ❌
```
特征：
  分论点极具哲学色彩——"流动孕育新生""新生反馈流动""新时代加速流动"
  全篇没有具体案例
  像是在写哲学论文而非申论大作文

代表：粉笔先申夺人（被评二类上24-26分）
避坑原因：申论是"议论文"而非"哲学论文"——光有理论没有论据=空洞
```

**第3类：抄材料型** ❌
```
特征：
  论据全部来自给定资料（玉陵湖大桥、凤凰河，没有任何自己的积累）
  没有"不拘泥于给定资料"的意识

代表：部分不具名的考生答案
避坑原因：题目明确要求"不拘泥于给定资料"——全抄材料=至少扣5分
```

### 🎯 各题型"避坑"速查表

| 题型 | 不能这样做 | 应该这样做 | 参考机构 |
|------|-----------|-----------|---------|
| **概括题** | 拔高升华（"巧在落实总书记要求"） | 直接提取原文关键词 | 粉笔、袁东 |
| **概括题** | 漏了"人才"采分点 | 5个核心名词：专班/平台/园区/资金/人才 | 千寻、小张申论 |
| **分析题** | 没有观点表态（江苏A卷） | 第一句直接亮明立场 | 华图（江苏）、粉笔（国考） |
| **分析题** | 只分析不提对策 | 问题+原因+对策三段式 | 唐棣、粉笔 |
| **应用文** | 格式不全（缺落款/称谓） | 标题+称谓+正文+落款+日期 | 粉笔、白鹭 |

## 附录：各主题代表性答案片段对照

### 科技创新主题

**好答案（粉笔·国考行政执法Q1）**：
> "促成科技成果转化。成立专班，深度对接高校院所，做好成果发现、挖掘、策划、转化工作。"

**差答案（湘一·国考副省Q1-玉陵湖大桥）**：
> "巧在象征着西部交通的完善"

→ 差在哪？概括题不需要"象征意义"。阅卷者只找"提篮拱桥""边建边拆"等原文关键词。

### 社会治理主题

**好答案（粉笔·国考执法Q2）**：
> "开展职工心声大调查活动。通过小程序收集意见建议，助推问题快速解决，增强沟通互动。"

→ 好在哪？每个动作对应一个具体的做法，没有虚词。

**差答案（某70分考生·同一题）**：
> "重视职工需求，通过小程序收集意见和建议，有效解决反馈的问题"

→ 差在哪？"重视职工需求"是虚的，不如"开展职工心声大调查活动"具体。

### 文化创新主题

**好答案（唐棣·2025江苏A卷Q1）**：
> "在文化传承上，《红楼梦》沉浸体验项目展现经典作品全新面貌，让观众感受文学力量与温度……"

→ 好在哪？归类清晰（按维度分），文采恰当（"文学力量与温度"）。

**差答案（Kiwi·同一题）**：
> "二是融合数字游戏，山西启动'跟着悟空游山西'、线上线下相融合，带动客流量和旅游消费"

→ 差在哪？归类方式可以但信息密度不够高，没有唐棣的"品牌创新"维度清晰。
