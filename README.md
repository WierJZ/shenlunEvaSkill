# 申论 Eva — 申论答案智能评估 Skill

基于国考+江苏省考十年真题（70份卷）、40+机构答案交叉对比、真实阅卷场校准的多角色串行评估引擎。

## 能力

- **全题型评分**：概括归纳、综合分析、对策题、应用文、大作文
- **手写图片识别**：手机拍照上传手稿，自动提取文字后评估
- **5层串行检查**：评分架构师 → 阅卷顾问 → 政府实务顾问 → 机构精析师 → 教学转化师
- **诊断报告**：总分/档位、失分点详解、维度雷达、改进优先级、3天刻意练习方案

## 安装

```bash
npx @wierjz/shenlun-eva
```

或通过 Claude Code 插件市场安装。

## 使用

### 文本答案

```
/申论Eva 这是2025国考副省第1题"概括A市促进高科技企业和新兴产业发展的主要做法"（10分/250字）。
给定材料：……（材料内容）
我的答案：1.成立科技成果转化专班，对接高校院所……
```

### 手写图片

上传手机拍摄的手写答案照片即可，Skill 会自动提取文字后进入评估流程。

### 快捷调用

直接说"帮我改一下申论""看看这个答案能拿多少分""申论诊断"即可触发。

## 评估输出

```
📊 评估总览 → 题型/总分/阅卷风险/政府思维/答题风格
🔍 失分点详解 → P0/P1/P2 优先级标注 + 正确做法示范
📈 维度雷达 → 采分点/逻辑/语言/政府思维/格式
🎯 改进优先级 → 最该先改的1-2个问题
📅 3天刻意练习 → 每天具体任务 + 验收标准
```
